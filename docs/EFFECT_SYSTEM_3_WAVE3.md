# 효과 시스템 3.0 · 3차 구현

2026-09-02. 2차 PR 내용 `3d124a8` 이후 변경. 카드 ID·슬롯·해금은 유지한다.

이번 묶음은 균열·조합 표식, 런 분할/합병과 카드 17종을 구현한다. 누적 개편은 **40종**, 기존 기능 유지 53종, 기존 카드 구현 대기 29종이다. 신규 SEASON-BLOOM 24종은 여전히 설계 단계다. 공식 상태는 13종이며 침묵·가변·잔향·불안정·반향과 표식의 카드 범위는 아직 지원하지 않는다.

ZERO-SIGHT는 전체 18종 중 14종을 변경하고 4종을 유지해 설계표의 목표 효과를 모두 구현했다. 이것은 효과 구현 완료이며 인간 대전 밸런스 확정을 뜻하지 않는다.

## 균열과 표식

| 상태 | 부여 | 처리 |
|---|---|---|
| 균열 | 살아 있는 공개 조합, 최대 1 | 다음 성공한 회수·재배치·개별 소모로 카드가 빠진 뒤 조합 제어자에게 일반 피해 6. 먼저 상태를 제거하고 반응. 보호막과 불굴 적용 |
| 표식 | 살아 있는 공개 조합, 부여자별 최대 1 | 양쪽 표식 공존. `내 표식`을 요구하는 효과는 자신이 부여한 것만 소비. 자체 피해 없음 |

상대 보드의 조합에 부여하면 조합 보호 1회가 부여를 막는다. 잘못된 대상·수치는 보호도 소비하지 않는다. 자기 조합에 부여하면 자기 보호를 소모하지 않는다. 재부여는 각 상한을 넘기지 않는다.

카드 이동을 실제로 확정한 다음 완료 이벤트를 발행한다. 균열은 테마 반응보다 먼저 소비하고, 같은 완료 패킷에 발동 여부를 전달한다. 따라서 데드 앵글은 이미 사라진 균열을 다시 조회하지 않고 그 행동으로 균열이 터졌는지 판정한다. 피해로 마지막 코어가 깨져도 카드 이동은 한 번 완료된 상태다.

조합 전체 정리는 균열을 발동시키지 않고 균열과 양쪽 표식을 버린다. 표적은 플레이어당 하나인 테마 메타데이터다. 표식을 여러 조합에 남길 수 있으며 표적 이전만으로 이전 조합의 표식이 지워지지 않는다.

## 절단선: 런 분할/합병

| 규칙 | 분할 | 합병 |
|---|---|---|
| 대상 | 내 보드의 6장 이상 런 하나 | 내 보드의 런 둘 |
| 결과 | 각각 3장 이상인 합법 런 둘 | 합치면 합법인 런 하나 |
| 슬롯 | 빈 슬롯 하나 필요 | 3슬롯이 가득 차도 가능 |
| 체인 | 두 결과에 기존 값 유지 | 원본 두 값의 최솟값 |
| 조합 상태 | 원본 첫 번째 물리 카드가 들어간 결과에 한 번만 이전 | 봉인·보호 합산, 균열 최대 1, 표식 부여자별 최대 1 |
| 카드 상태·소유권 | 모두 유지 | 모두 유지 |

고정된 조합과 고정 카드가 들어간 런은 대상이 될 수 없다. 인쇄 숫자·선택한 사용값·조커·기존 런 예외는 현재의 실제 합법 판정을 그대로 따른다. 두 결과에 같은 UID가 들어가거나 빠질 수 없으며 카드 객체도 교체하지 않는다. 선택 후 원본 카드 구성이 달라졌으면 적용하지 않는다.

선택창에서 모든 합법 분할/합병과 건너뛰기를 제공한다. 분할 표시의 첫 번째 결과가 기존 조합 상태를 받는다. AI도 같은 후보를 사용해 우선 합병으로 슬롯을 확보하고, 합병이 없으면 길이가 균형 잡힌 분할을 선택한다. 이 판단은 최적 전략을 보장하지 않는다.

원래 카드 사용의 위력·반환·테마 반응·세트 정리를 먼저 해결한 뒤 변형을 선택한다. 변형 선택이 끝난 뒤 현재 손패로 러미를 판정한다. 취소해도 원래 사용 행동의 마무리는 한 번 수행된다.

분할/합병은 `onMeldReshape` 한 번으로 기록한다. 회수·새 조합 생성·조합 정리 이벤트를 대신 발행하지 않는다. 생성 횟수를 환불하거나 늘리지 않고 스위치 위력·반환 횟수를 바꾸지 않는다. 결과 조합은 현재 턴에 붙일 수 없다. 기존 표적·접전은 해제하며 조합에 묶인 회수 재사용 권한도 새 조합으로 이전하지 않는다.

## 표식을 쓰는 반환의 순서

1. 스위치 대상과 턴당 실제 반환 제한을 검사한다. 실패하면 표식·반환 상태를 소비하지 않는다.
2. 사용한 네임드 효과 순서대로 장거리 사격·탄도 계산·ONE SHOT의 표식 비용을 해결한다. 하나의 표식을 두 효과가 쓸 수 없다.
3. 장거리 사격은 장전 16을 부여한다. 내 표식이 있으면 소비하고 감쇠 최대 8을 제거한다.
4. 일반 반환의 ONE SHOT은 내 표식이 있으면 +18, 없으면 과열 10. 조건은 **이 행동 시작 전** 누적 위력 50 이상이다. 50 미만에서는 이 효과가 없고 자가 봉인도 없다.
5. `max(0, 행동 위력 + 장전 + 과열 − 감쇠)`를 계산한다.
6. 탄도 계산이 내 표식을 소비했다면 상대 현재 코어+보호막+불굴과의 부족분을 최대 12만큼 추가한다. 이미 충분해도 표식 비용은 소비한다.
7. 누적 위력 갱신, 스위치 방향 변경, 반환 횟수 소비, 과열 반동 순서로 처리한다.

무가산 반환은 탄도 계산·ONE SHOT의 표식을 소비하지 않는다. 장거리 사격의 장전 획득·감쇠 해제는 적용하지만 무가산 반환 자체가 장전·감쇠·과열을 소비하지는 않는다. 같은 런의 연속 붙이기는 새 실제 반환이 아니므로 이 처리도 반복하지 않는다.

관측 기록은 해당 카드가 그 표적에 공개된 상태로 다음 자기 턴 시작까지 있어야 한다. 이후 그 턴 첫 붙이기 완료 시 장전 8을 받는다. 대상 이전, 공개 이탈, 조합 변형으로 이전 관측 기간을 우회할 수 없다. 역추적은 상대 실제 반환 완료 시 공용 장전 12를 주므로 원본 카드가 정리되어도 준비한 장전은 남는다.
