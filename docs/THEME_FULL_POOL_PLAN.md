# RUMMY//DUEL — THEME FULL POOL PLAN

Updated: 2026-09-02
Status: ACTIVE IMPLEMENTATION POLICY

이 문서는 정식 카드군을 더 이상 소수 샘플 카드만 라이브한 채 완성 취급하지 않고, **정식 후보 풀 전체를 구현한 뒤 하나의 카드군으로 릴리스**하기 위한 작업 기준을 잠근다.

## 1. 풀 카드군의 정의

앞으로 `카드군 라이브`는 아래를 전부 만족해야 한다.

1. `docs/THEME_GROUPS.md`에 잠긴 정식 후보 카드 전체가 `NAMED` 변형으로 존재한다.
2. 모든 카드의 효과가 실제 전투 엔진에서 발동한다. 설명만 있고 미구현인 카드는 허용하지 않는다.
3. 같은 랭크+무늬 물리 슬롯 충돌을 덱빌더가 정상 처리한다.
4. 해금 조건과 카드 도감 표시가 연결된다.
5. 테마 빌드가 일반 카드/다른 테마와 섞이는 오픈형 9장 네임드 모듈 규칙을 지킨다.
6. 플레이어 선택이 필요한 효과는 공용 재개형 선택 UI를 사용한다.
7. AI가 별도 치트 규칙 없이 합법 행동 안에서 효과를 사용할 수 있다.
8. 로그라이크 보상·적 덱에 넣을 수 있는 카드와 제외할 카드를 명시한다.
9. 단일 테마·2테마 혼합·일반 mixed 회귀를 통과한다.
10. 카드군별 핵심 루프를 실제로 검증하는 전용 회귀 테스트가 존재한다.

개발 과정에서는 여러 작은 커밋/웨이브로 나눌 수 있지만, 사용자에게는 위 조건이 완료되기 전까지 `개발 중`으로 취급한다.

## 2. 현재 우선순위 — 기존 3테마 60장 완성

현재 먼저 끝낼 카드군은 아래 세 개다. 새 정식 카드군의 라이브 구현은 이 세 카드군의 풀 구현보다 뒤로 둔다.

| 카드군 | 정식 후보 | 현재 main 라이브 | 남은 구현 | 목표 |
|---|---:|---:|---:|---:|
| V-SIGNAL | 24 | 24 | 0 | 24/24 |
| ZERO-SIGHT | 18 | 18 | 0 | 18/18 |
| POINT-BLANK | 18 | 18 | 0 | 18/18 |
| **합계** | **60** | **60** | **0** | **60/60** |

현재 main의 라이브 기준은 다음과 같다.

- V-SIGNAL: **24/24 풀 구현 완료**
- ZERO-SIGHT: **18/18 풀 구현 완료**
- POINT-BLANK: **18/18 풀 구현 완료**

`CARD_EXPANSION_WAVE_01.md`에서 설계한 18장은 이 51장 잔여 구현 안으로 흡수한다. 별도의 소규모 카드군 확장으로 끝내지 않는다.

## 3. 구현 순서

### F0 — 증원 기반 정리

- 이전 Wave 01A에서 만든 카드 정의/효과 코드를 현재 main에 안전하게 재적용한다.
- 카드 증가로 드러난 자동 테마 빌드 최대 4장 상한 우회를 수정한다.
- 2테마 혼합은 각 테마 최대 4장, 최소 1장의 비테마 공간을 유지한다.
- 기존 로그라이크 보상/지역 적 덱의 고정 결과는 카드 풀 증가만으로 암묵적으로 바꾸지 않는다.

### F1 — V-SIGNAL 24/24 · 완료

24장 전체 정의·실전 효과·해금·도감/덱빌더 연결을 완료했다. 신규 21장은 60장 통합 전까지 기존 로그라이크 지역 적 덱에는 넣지 않고, 일반 랜덤 보상 순위에서도 후보가 충분할 때 우선 제외한다.

우선 구현 축:

1. 방송 초동 — `첫 방송`, `신인 2기생`, `ON AIR`
2. 상대 조합 진입 — `RAID`, `팬 서비스`, `슈퍼챗`
3. 세트/런 교차 — `3인 합방`, `게임 방송`, `콜라보 신청`
4. 회수/보존 — 기존 `앙코르`, `전원 집합!`, `24시간 내구방송`과 신규 회수 카드 연결
5. 러미/생존 — `기념 방송`, `100만 구독`
6. 압박/피니셔 — 염상·논란·BAN 계열은 직접 누적 위력 카드 비율을 낮게 유지

완료 게이트:

- 24개 정의 + 24개 실제 효과
- V-SIGNAL 전용 회귀
- 일반/다른 테마 카드가 합방·RAID·회수 루프에 참여 가능
- HYPE 등 전용 숫자 자원 없음

**F1 완료 기록** — 2026-09-02. `tests/vsignal-full-pool.mjs`, 기존 `tests/vsignal-mixed-regression.mjs`, 확장형 `tests/theme-mix-simulation.mjs` 및 전체 회귀를 릴리스 게이트로 사용한다.

### F2 — ZERO-SIGHT 18/18 · 완료

18장 전체 정의·실전 효과·해금·도감/덱빌더 연결을 완료했다. 신규 14장은 60장 통합 전까지 기존 로그라이크 지역 적 덱에는 넣지 않고, 일반 랜덤 보상 순위에서도 후보가 충분할 때 우선 제외한다.

핵심 구현 축:

- 표적 생성/이전/해제
- 덱 위 정보 및 패순환
- 표적 조합 회수·이동 반응
- `handPrep` 준비 카드
- 봉인/고정/보호 등 공식 상태 재사용
- 직접 위력 보정은 `탄도 계산`, `철갑탄`, `장거리 사격`, `ONE SHOT` 등 제한된 카드만 담당

완료 게이트:

- 18/18 구현
- 표적 1개 계약 위반 없음
- 표적 조합의 카드는 ZERO-SIGHT일 필요 없음
- V-SIGNAL 회수 및 POINT-BLANK 접전과 같은 조합에서 공존

**F2 완료 기록** — 2026-09-03. `tests/zero-sight-full-pool.mjs`와 기존 ZERO-SIGHT 표적/준비/탄도/ONE SHOT/혼합 회귀 및 전체 `tests/*.mjs`를 릴리스 게이트로 사용한다.

### F3 — POINT-BLANK 18/18 · 완료

18장 전체 정의·실전 효과·해금·도감/덱빌더 연결을 완료했다. 신규 16장은 60장 통합 전까지 기존 로그라이크 지역 적 덱에는 넣지 않고, 일반 랜덤 보상 순위에서도 후보가 충분할 때 우선 제외한다.

핵심 구현 축:

- 접전 생성/이전

- 회수/무료 회수

## 5. 후속 카드군 정책

### MAIL-ROUTE

- 정식 후보: 28장 / 수트별 7장
- 현재 상태: **28/28 라이브 구현 완료**
- 정책: `우편/목적지/도착/반송` 공용 계약과 28장 효과가 일반 플레이 풀에 통합되어 있다.

### SCRAP-SHIFT

- 정식 후보: 24장 / 수트별 6장
- 현재 상태: **24/24 라이브 구현 완료**
- 정책: `부품/해체/이식/재조립` 공용 계약과 24장 전체 효과를 일반 플레이 풀에 통합했다. 전체 1~6클리어에서 4장씩 단계 해금되며, 도감·자동 테마 빌드·SCRAP-SHIFT 체험전·아이언그레이브 지역 보상에도 연결된다.

### TWELVE-BLOOM / CYCLE-WORKS 및 이후 후보

TWELVE-BLOOM은 구 HWA-TU를 대체하는 이름으로 기본 판정과 24장 후보 풀까지 잠갔지만 아직 비라이브다. `docs/TWELVE_BLOOM_DESIGN.md`의 match evaluator·윤달 수명주기·상황형 UI를 먼저 구현하고 회귀를 통과하기 전에는 카드군 선택/해금/일반 보상에 넣지 않는다. CYCLE-WORKS 및 그 이후 후보도 같은 원칙을 따른다.
