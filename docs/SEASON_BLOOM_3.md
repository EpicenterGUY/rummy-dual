# SEASON-BLOOM · 3.0 신규 설계

사용자가 논의한 화투 모티브의 계절 테마를 SEASON-BLOOM으로 재설계한다. **24장 설계 완료, 런타임 미구현**이다. HWA-TU의 옛 그림맞춤/윤달 후보를 동시에 활성 규칙으로 취급하지 않는다. 신규 ID는 기존 카드와 충돌하지 않는 SB 접두사이며, 설치 시 기존 슬롯 변형 규칙을 따른다.

## 공용 카드로 계절을 만든다

- 봄: 원래 숫자 A·2·3, 여름: 4·5·6, 가을: 7·8·9, 겨울: 10·J·Q.
- 양쪽 보드에 공개된 **내가 현재 제어하는 카드**를 통틀어 해당 숫자 셋이 모두 있으면 완성이다. 카드군/무늬/같은 조합 여부는 묻지 않는다. 각 숫자는 실물 UID 하나씩 필요하다.
- 원래 숫자는 카드의 원본 슬롯 숫자다. 가변/대역/비대칭 카드의 사용값은 실제 SET/RUN에만 쓰고 계절을 속이지 않는다. K·조커는 기본 계절 재료가 아니다. 윤달/그림맞춤은 이번 설계에서 제외한다.
- 공개 카드 1장이 회수되거나 소유권을 잃으면 즉시 전체 완성 상태를 다시 계산한다. 손패/버림패/소모패의 카드는 참여하지 않는다.

## 새 완성과 전환

원자적인 성공 행동의 전·후 전체 보드를 비교해 미완성→완성인 계절만 `새 완성`이다. 같은 계절의 새 완성 보상은 플레이어별 턴당 한 번까지만 허용한다. 회수→재진입 반복으로 횟수를 늘리지 않는다. 여러 계절을 한 행동에 새로 완성하면 각각 한 번이며 봄→여름→가을→겨울 순서로 해결한다.

`전환`은 이번 행동 전에 가장 최근 새로 완성했던 계절과 다른 계절을 이번 행동으로 새로 완성한 경우다. 첫 완성은 전환이 아니다. 비교 기준은 행동 시작 때의 기록으로 고정하므로 한 행동에서 두 계절을 완성했다고 서로가 서로의 전환 조건을 인위적으로 충족하지 않는다. 마지막 계절 기록은 이벤트 해결 후 갱신한다. 이 기록은 소비 자원이나 중첩 카운터가 아니다.

같은 행동으로 들어온 카드는 그 행동의 완성 후속을 읽을 수 있다. 침묵 중인 공개 반응 카드는 발동하지 않는다. 회수/재배치 자체는 네임드 진입 효과를 다시 발동하지 않는다. 준비·계절·고유효과의 횟수 제한은 각각 카드와 공용 관문으로 검사한다.

## 기능과 혼합

봄은 손패 준비·귀환, 여름은 재배치·균열/과열, 가을은 자원 보존·장전, 겨울은 불굴·감쇠/유예로 설계한다. 아무 순수 카드의 숫자도 계절을 완성할 수 있어 테마 전용 카드만 요구하지 않는다. V-SIGNAL의 회수는 계절을 열고 닫으며, POINT-BLANK 안의 내 카드도 계절 재료이고, ZERO-SIGHT 표적에 놓인 내 카드 역시 같은 조건으로 센다.

24장 전체 목표 효과는 [전체 설계표](CARD_REDESIGN_3.md#season-bloom-신규-설계--24종)를 따른다. 설계만으로 라이브 카드군을 완료 취급하지 않는다. 다음 게이트가 남아 있다.

- 계절 전/후 스냅샷 및 원자적 이벤트, 복수 완성/회수 루프/소유권 변경 테스트
- 상태 7종 중 이 카드군이 요구하는 균열·침묵·가변 등 실제 구현
- 선택형 순환/재배치/교환과 플레이어·AI의 동일 후보 검증
- 24종 전체 슬롯·해금·도감·혼합 덱/보상 검증
- 사람이 확인한 패말림·위력·계절 전환 빈도·모바일 가독성
