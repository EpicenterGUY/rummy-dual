# 효과 시스템 3.0 — 6차 구현: 침묵과 반응 공통 처리

2026-09-03 · PR #35의 5차 구현 `b1f0496` 이후 묶음. 기존 카드 61종 개편·53종 유지·8종 구현 대기, 공식 상태 14/18종이다. 이 문서의 변경은 대개편 브랜치에 적용하며 main 병합·배포와 구분한다.

## 적용 카드 3종

| ID | 카드 | 적용 효과 |
|---|---|---|
| S9 | 잠복자 | 손에서 자기 턴을 2회 넘긴 뒤 사용하면 상대 제어 공개 카드 1장에 침묵. 이미 침묵이면 대신 상대 감쇠 12 |
| VSD6 | 슈퍼챗 | 이 카드의 공개 조합에 상대가 붙이면 1장 획득 후 다음 자기 턴 종료까지 침묵. 양쪽 보드에서 카드 제어자 기준으로 반응 |
| PBS3 | 플래시뱅 | 내 접전에 붙이면 그 조합의 상대 제어 카드 1장에 침묵. 이미 침묵이면 대신 그 조합에 균열 |

잠복자는 공용 손패 준비 기록으로 자기 턴 종료 2회를 센다. 나갔다가 손패에 들어오면 준비가 초기화된다. 잠복자/플래시뱅은 후보가 여러 장이면 정확한 카드 선택을 받고, 후보 하나와 CPU는 같은 경로로 즉시 해결한다. 선택을 기다리는 동안 반환·완료 반응을 보류하고 해결 뒤 한 번만 재개한다. 필수 선택은 건너뛸 수 없다. 선택 후 소유권/위치/접전/전투·턴을 다시 검사한다.

슈퍼챗은 재진입 방지를 위해 침묵 상태를 먼저 확정하고 카드를 뽑는다. 이미 침묵한 슈퍼챗은 상대의 같은 런 추가 연장에도 반응하지 않는다. 진입 효과로 부여한 침묵은 해당 붙이기의 공개 반응보다 먼저 적용된다.

## 공통 침묵 규칙

- 카드 상태이며 값은 비중첩 1. 유한한 양의 정수 부여만 허용한다.
- 만료는 부여 당시 카드 제어자의 다음 턴 종료다. 현재 자기 턴에 받았다면 이번 종료에는 남고 다음 자기 턴 종료에 풀린다. 상대 턴에 받았다면 돌아오는 자기 턴 종료에 풀린다.
- 소유권 변경은 기존 만료 주체를 바꾸지 않는다. 재부여 시 새 만료가 더 늦으면 새 부여의 주체·시점을 저장한다. 양쪽 손패·덱·소모패·공개와 공용 버림패를 모두 검사한다.
- 만료 처리는 턴 종료 폭발과 기록 이후다. 종료 시점까지 심장왕 등 손패 반응은 정지한다. 카드의 봉인 횟수는 침묵 부여/반응 차단으로 소비하지 않는다.
- `canTrigger(card,timing)`은 조회 과정에서 카드를 변경하지 않는다. `use`는 진입 1회 효과이고 침묵을 통과한다. 지속/반응 조회는 침묵이면 거절한다. 실제 진입 해결의 기존 플레이어/조합/카드 봉인은 유지한다.
- 상태 귀환·균열과 완료된 행동에서 등록한 예약/허가/약정은 출처의 능력과 별개다. 원본 침묵으로 소급 취소하지 않는다. 기본 러미 재충전, 손패 보유 시간, 회수/붙이기 등의 행동 이력도 계속 처리한다.

## 기존 공개 역할의 유지

침묵을 이유로 합법이던 공개 조합을 깨지 않도록, 해당 원본이 이미 제공한 구조 역할만 고정한다. 손패에서 침묵한 카드는 새 구조 보조 능력을 제공하지 못한다.

| 능력 | 침묵 동안 유지하는 구체적 역할 |
|---|---|
| 대역 배우·밀수품 | 기존 공개 런에서 사용한 무늬 |
| 도플갱어 | 기존 공개 세트에서 복사한 숫자 |
| 위조범 | 기존 공개 런에서 사용한 ±1 범위의 실제 숫자 |
| 샛길 | 기존에 비어 있던 숫자 한 칸. 다른 빈 숫자로 바꿀 수 없음 |
| 밀수업자 | 자신의 사용 무늬와 이미 허용한 다른 무늬 카드의 UID. 새 카드에 허용을 줄 수 없음 |

인쇄 숫자·무늬·위/아래 선택과 조커의 와일드 재료 성질은 유지한다. 고정 역할은 공개 기간에만 유지하고 회수·정리·개별 소모 시 해제한다. 침묵 해제 시 원래 지속 능력이 재개된다. 원래 인쇄값을 덮어쓰지 않는다.

## 보호와 대상 교대

상대 공개 카드인지 먼저 검증한 뒤 카드 보호 → 적대 조합 보호 → 보험 대체 → 엄폐 교대를 처리한다. 교대된 카드의 개별 보호도 검사한다. 행동 주체의 조합 보호는 그 조합 안에 있는 상대 카드를 행동 주체의 효과로부터 보호하지 않는다.

최종 확정된 카드가 이미 침묵인지 확인한 뒤 감쇠/균열 대체 효과를 적용한다. 보호로 막힌 부여는 침묵/대체 상태를 만들지 않고, 잘못된 대상은 보호나 교대 횟수도 소모하지 않는다. 침묵한 보험설계사·엄폐 교대는 방어 반응을 새로 발동하지 못한다.
