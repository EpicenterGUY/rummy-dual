# RUMMY//DUEL — Roguelike Master Plan (Working Draft)

Updated: 2026-09-01

이 문서는 RUMMY//DUEL의 로그라이크 확장에 대해 현재까지 논의한 **캐릭터/스타터, 순수카드, 테마군, 지역, 카드 보상, 런 구조**를 한곳에 보존하는 작업용 설계안이다.

중요: `FINAL CORE 2.0`의 전투 규칙을 바꾸는 문서는 아니다. 아래에서 **v1 잠금**으로 명시한 스타터 30장 구조, 순수/네임드 비율, 직접 전투 패시브 없음, 캐릭터 보상 후보 랭킹 가중치는 현재 구현 기준으로 고정한다. 실제 보상 등장 확률, 카드 희귀도, 지역 수, 런 경제와 PURE 전용 특전은 플레이테스트 이후 조정한다.

## 1. 로그라이크의 핵심 방향

- 완성된 테마덱을 고르고 시작하는 구조보다 **스타터가 방향만 제시하고 런 도중 덱이 변하는 구조**를 우선한다.
- 기본 흐름 후보는 `스타터 선택 → 공통 시작 구역 → 지역 분기 → 지역별 카드풀/이벤트 → 중간 보스 → 추가 지역 선택 → 후반 특수구역 → 최종 보스`다.
- 순수 트럼프가 덱의 뼈대이며, 네임드 카드는 숫자/무늬 구조 위에서 규칙을 비튼다.
- 테마군은 서로 섞일 수 있어야 하며, 지역 선택은 특정 테마를 강제하기보다 해당 플레이스타일의 등장 확률을 높인다.
- 같은 스타터라도 런 후반에는 시작과 전혀 다른 혼합덱이 될 수 있어야 한다.

## 2. 캐릭터 / 스타터 방향

캐릭터는 특정 카드군만 사용할 수 있는 클래스가 아니라 **런의 출발 방향**이다.

후보 요소:

- 순수 트럼프 다수 + 해당 성향의 효과카드 소수
- 특정 행동 또는 지역/테마 카드 보상 가중치
- 작은 고유 패시브 또는 시작 유물
- 다른 테마 및 다른 지역 카드 획득은 항상 허용

캐릭터 선택만으로 완성 콤보를 지급하지 않는다. 예를 들어 V-SIGNAL 성향 캐릭터로 시작해도 런 중 ZERO//SIGHT, MAIL//ROUTE, POINT//BLANK 등으로 자유롭게 전환하거나 혼합할 수 있다.

v1 잠금 항목:

- 모든 스타터 시작 덱은 30장 = 정규 슬롯 29 + 조커 1.
- 유랑자/수집가/회수꾼/광대는 순수 23 + 네임드 정규 6 + 네임드 조커 1.
- PURE는 순수 정규 29 + 기본 와일드 조커 1이며 네임드/효과카드 0장.
- 직접 전투 패시브는 전원 없음. 스타터 차이는 시작 네임드 구성과 보상 후보 랭킹으로 만든다.
- 보상 후보 랭킹은 현재 `CHARACTERS.weights`를 그대로 쓰는 `character-tendency-score-v1` 소프트 가중치다. 가중치는 후보 점수에만 관여하고 다른 카드군을 금지하지 않는다.

계속 미확정인 항목:

- 6개의 시작 네임드 정규 슬롯에 들어갈 실제 카드 ID와 네임드 조커의 스타터별 세부 선택 규칙
- 실제 보상 등장 확률 / 희귀도 / 전투 등급별 경제
- 캐릭터와 지역의 관계
- PURE 전용 외부 특전/유물

## 3. PURE — 온리 순수 스타터

`PURE`는 별도 테마 카드군이 아니라 **효과카드 0장으로 시작하는 백지형 스타터/빌드 경로**다.

방향:

- 모든 시작 카드는 효과 없는 순수 트럼프.
- 숫자/무늬 분포는 v1에서 공통 정규 29슬롯 `S3,S4,S5,S6,S7,S8,S9,H2,H3,H4,H7,H8,H9,D2,D3,D4,D5,D6,D7,D8,C3,C4,C5,C6,C7,C8,C9,S10,H10`으로 잠근다.
- 런 중 어떤 카드군으로도 전환 가능하다.
- 끝까지 네임드 카드를 받지 않는 온리 순수덱 클리어도 가능하게 한다.
- 순수덱 지원은 새 전용 카드군보다 유물/패시브/이벤트 등 카드 외부 시스템을 우선 검토한다.
- PURE의 장점은 직접 전투 보너스보다 카드 선택/교체/제거 자유도 쪽에 둔다.

후보 특전은 카드 보상 선택지 +1, 네임드 교체 비용 감소, 제거/슬롯 조정 비용 감소 등이 있으나 아직 확정하지 않는다.

## 4. 순수카드 → 네임드화 성장

로그라이크의 주요 차별점으로 **같은 랭크+무늬 슬롯의 순수카드를 네임드 변형으로 교체/진화**시키는 방식을 우선 검토한다.

예:

`7♠ 순수 카드 → 7♠ 검은 탄환`

또는 동일 7♠ 슬롯의 다른 테마 변형으로 교체한다.

원칙:

- 숫자와 무늬는 보존한다.
- 세트/런 분포를 무너뜨리지 않고 효과 정체성을 성장시킨다.
- 모든 순수카드를 네임드화하는 것이 자동 정답이 되어서는 안 된다.
- 성장 방식은 `교체 / 추가 / 제거` 세 축을 검토한다.
- 교체는 기본 성장 수단, 추가/제거는 더 희소한 수단으로 두는 방향이 유력하다.

## 5. 카드 보상 구조

일반 전투 보상 후보는 기본적으로 **3장 중 1장 선택 + 건너뛰기**를 우선 검토한다.

세 슬롯의 역할을 다르게 두는 안:

1. 현재 빌드 강화 — 현재 덱의 행동과 직접 시너지
2. 확장/새 방향 — 새로운 테마 또는 혼합 빌드의 초동
3. 기반 보강 — 범용 네임드, 순수 슬롯 개선, 숫자/무늬 보정

보상은 `V-SIGNAL 카드가 많다` 같은 단순 테마명 검사만 보기보다 실제 덱 행동 태그를 함께 본다.

예시 행동 태그:

- 새 세트 생성
- 런 생성/확장
- 상대 조합 붙이기
- 회수
- 정비
- 버림패 이용
- 스위치 반환
- 러미
- 상태 부여/해제

따라서 회수 중심 덱에는 V-SIGNAL뿐 아니라 MAIL//ROUTE, POINT//BLANK, SCRAP//SHIFT 등 관련 카드가 새 방향 후보로 나타날 수 있다.

## 6. 새 테마 진입과 보상 단계

새 카드군을 처음 발견했을 때 피니셔만 덜렁 등장하는 문제를 막기 위해 테마 내부 역할 단계를 둔다.

`초동 → 엔진 → 보상 → 피니셔`

- 처음 진입 시 초동/기본 엔진의 출현 가중치를 높인다.
- 실제 덱에 전용 개념 생성 수단이 생기면 중급 엔진을 연다.
- 엔진이 갖춰진 뒤 강한 보상/피니셔가 자연스럽게 등장하도록 한다.
- 별도 `테마 레벨` 자원을 만드는 대신 현재 덱에 실제로 어떤 기능이 있는지 검사하는 방식을 우선한다.

전투 등급별 보상 방향 후보:

- 일반전: 초동 / 기본 엔진 / 범용 / 기반 개선
- 엘리트: 강한 엔진 / 규칙 변형 / 희귀 유물
- 보스: 피니셔 / 시그니처 / 대규모 카드 개조

## 7. 지역 기반 카드풀

`테마군 하나 = 지역 하나`로 고정하지 않는다.

대신 **지역 = 공통 문화/환경 + 서로 어울리는 여러 테마군 + 지역 공용 카드** 구조를 우선 검토한다.

새 카드군을 만들 때도 먼저 지역의 문화, 직업, 갈등, 인프라를 만들고 거기서 여러 집단/테마군이 파생되게 하는 방향이 유력하다.

카드 계층 후보:

`전역 범용 → 지역 공용 → 테마군 → 캐릭터 고유`

지역 공용 카드는 같은 지역의 서로 다른 테마군이 공유하는 행동 축을 지원한다.

## 8. 공통 시작 구역

런 초반은 특정 테마 지역으로 바로 들어가기보다 **공통 구역에서 빌드의 씨앗을 찾는 구조**를 우선한다.

공통 구역 후보 보상:

- 순수카드/슬롯 개선
- 범용 네임드
- 여러 테마의 초동 카드
- 상점
- 이벤트
- 기본 유물

이후 플레이어가 현재 덱의 방향을 보고 지역을 선택한다.

즉 `지역이 빌드를 정한다`보다 **카드가 씨앗을 주고 지역이 그 방향을 밀어준다**는 순서를 우선한다.

## 9. 지역 후보

### NEON//ARC — 네온아크

미디어, 가상 방송, SNS, 광고, 배송, 정보망이 밀집한 초고밀도 상업도시.

현재 연계 테마 후보:

- `V-SIGNAL`
- `MAIL//ROUTE`

향후 해커, 기자, 광고, 데이터 브로커 계열 등을 추가할 수 있다.

주요 행동 성향 후보: 정비 / 회수 / 카드 이동 / 패순환 / 정보 전달.

### RED//ZONE — 레드존

도시전, 용병, 정찰, 돌입전이 이어지는 분쟁구역.

현재 연계 테마:

- `ZERO//SIGHT`
- `POINT//BLANK`

향후 폭파병, 의무병, 용병, 드론 정찰 계열 등을 추가할 수 있다.

주요 행동 성향 후보: 상대 조합 붙이기 / 표적 / 접전 / 고정 / 봉인 / 스위치 압박.

### IRON//GRAVE — 아이언그레이브

폐공장, 고철 산, 버려진 기계와 로봇이 쌓인 산업폐허.

현재 연계 테마 후보:

- `SCRAP//SHIFT`

향후 로봇, 공장, 중장비, 기계공 테마 등을 추가할 수 있다.

주요 행동 성향 후보: 회수 / 소모 / 이동 / 부품화 / 재조립.

### OLD//QUARTER — 올드쿼터

낡은 골목, 사설 탐정, 범죄조직, 암시장, 오래된 상점과 계약이 얽힌 구시가지.

향후 후보:

- 탐정
- 마피아/조직
- 도둑
- 밀수
- 계약/거래

주요 행동 성향 후보: 버림패 / 정보 / 거래 / 방해 / 상대 행동 추적.

### NULL//WARD — 널워드

기록과 지도에서 삭제된 격리구역. 실험실, 이상현상, 변이체와 버려진 시설이 남아 있다.

향후 후보:

- 실험체
- 초능력
- 괴이
- 저주
- 변이

주요 행동 성향 후보: 카드 변형 / 상태 / 위험한 규칙 예외 / 고위험 고보상.

초기부터 갈 수 있는 지역인지 후반 특수구역인지 아직 미정이며, 후반 지역으로 사용하는 안이 유력하다.

## 10. 지역 보상은 확률 가중 방식

한 지역에 들어갔다고 해당 테마만 등장하지 않는다.

예를 들어 네온아크에서는 V-SIGNAL과 MAIL//ROUTE 및 네온아크 공용 카드의 비중이 높아지지만, 범용 카드와 소량의 타지역 카드도 등장할 수 있다.

지역 선택의 의미는 `이 테마를 강제로 한다`가 아니라 **이런 플레이스타일이 잘 나오는 환경으로 간다**에 둔다.

정확한 비율은 미정이다.

## 11. 현재 테마군과 지역 관계

- `V-SIGNAL` — 네온아크 중심 후보. 방송/합방/RAID/회수/러미.
- `MAIL//ROUTE` — 네온아크 중심 후보. 우편 지정/목적지/도착/반송/재배송.
- `ZERO//SIGHT` — 레드존 중심. 표적/관측/정밀 타격.
- `POINT//BLANK` — 레드존 중심. 접전/침투/회수/교대.
- `SCRAP//SHIFT` — 아이언그레이브 중심 후보. 부품/해체/재조립.

기존 테마의 상세 카드 효과는 별도 테마 문서에서 관리한다. 이 문서는 지역/로그라이크에서의 위치를 기록한다.

## 12. 혼합 빌드의 목표 경험

예시 A:

`PURE → 공통 구역에서 ZERO//SIGHT 초동 → 레드존 → 표적/접전 혼합 → 네온아크 → MAIL//ROUTE 획득 → 표적 조합을 목적지로 사용`

예시 B:

`V-SIGNAL 성향 캐릭터 → 네온아크 → RAID/회수 중심 → 아이언그레이브 → SCRAP//SHIFT 획득 → 방송 카드를 부품화하는 혼합덱`

스타터는 목적지가 아니라 출발점이어야 한다.

## 11. 런 초기화 구조 프로토타입

일반 1대1 전투의 `캐릭터 경향 + 테마 + 30장 덱빌더`와 로그라이크 시작 선택을 분리한다. 로그라이크 스타터는 `유랑자 / 수집가 / 회수꾼 / 광대 / PURE` 다섯 출발점을 별도 UI에서 고르며, 캐릭터 선택은 **보상·행동 방향의 힌트**이지 특정 테마 카드군 잠금이 아니다.

현재 `rummyDuelRoguelikeRunDraftV1` 초안 구조는 다음 원칙만 확정한다.

- 모든 런은 `common-start` 공통 시작 구역에서 출발한다.
- `themeLocks`는 항상 빈 배열이며 타 테마 카드 보상을 허용한다.
- 지역 경로와 노드 위치는 빈 경로/0에서 시작한다.
- 카드 슬롯 정체성은 기존 `base rank + suit`를 유지한다.
- PURE는 시작 시 네임드 0장을 확정한다. 그러나 런 중 네임드 획득은 허용한다.
- 다른 캐릭터는 `순수 다수 + 효과카드 소수` 방향만 보존하며 정확한 시작 덱 장수와 비율은 아직 넣지 않는다.
- 캐릭터 패시브와 실제 카드 보상 확률/가중치 수치는 `unresolved`로 둔다. 기존 일반전 덱 생성 가중치를 로그라이크 확률로 오인해 재사용하지 않는다.
- 현재 단계의 `prepared` 초안은 전투에 자동 연결하지 않는다. 지역/보상/스타터 수치가 확정된 뒤 실제 run session으로 승격한다.

## 12. 행동 태그 기반 카드 보상 후보 알고리즘 v1

`action-tags-v1`은 실제 보상 확률표가 아니라 **후보 랭킹 계층**이다. 기존 일반전 캐릭터 가중치를 그대로 드롭 확률로 재사용하지 않고, 네임드 효과 태그를 플레이어가 이해할 수 있는 행동 태그(`세트 / 런 / 붙이기 / 회수 / 정비 / 러미 / 버림패 / 스위치 / 상태 / 상대 조합 / 규칙 변형`)로 정규화한 뒤 현재 런 덱과 비교한다.

기본 3역할은 다음과 같다.

1. `현재 강화` — 현재 덱에서 이미 반복되는 행동과 겹치는 카드에 높은 점수를 준다. 스타터 성향은 작은 tie/방향 보정일 뿐 확률 잠금이 아니다.
2. `새 방향` — 현재 덱에 없는 행동과 새 테마를 우선한다. 새 테마에 이미 초동 메타가 정의되어 있으면 초동을 먼저 올리고, 초동 없이 피니셔만 제시하는 후보는 낮춘다. 현재 라이브 기준 ZERO-SIGHT는 `관측수 / 스코프 조정`이 `ONE SHOT`보다 첫 진입 우선이다.
3. `기반 보강` — 테마 의존도가 낮은 범용 카드와 정비/회수/버림패 같은 순환 기반 행동을 우선한다.

현재 v1의 후보 풀은 **덱에 이미 존재하는 원본 rank+suit 슬롯의 네임드 교체**로 제한한다. 현재 장착 중인 동일 변형, 조커, 덱에 없는 슬롯은 제외한다. 이는 `교체`를 기본 성장축으로 둔 기존 원칙을 따른 것이며 `추가 / 제거` 보상의 경제가 확정되기 전까지 서로 섞지 않기 위함이다.

세 역할은 가능한 경우 서로 다른 카드를 뽑고 `건너뛰기`는 항상 별도 선택지로 유지한다. 같은 입력과 seed에서는 결과가 결정적이라 회귀/밸런스 비교가 가능하다. 캐릭터/테마 하드 잠금은 만들지 않으므로 새 방향 역할에서 다른 테마 카드가 정상적으로 등장할 수 있다.

현재 진행도 화면의 개발 미리보기는 실제 로그라이크 덱이 아직 없기 때문에 기존 29슬롯 덱빌더를 **구조 대역**으로만 사용한다. 이 미리보기 결과는 전투, 해금, 보상 저장에 반영되지 않는다.

아직 확정하지 않는 것:

- 일반전 / 엘리트 / 보스별 희귀도와 보상 등급
- 실제 드롭 확률과 역할별 등장 확률
- 카드 추가/제거의 경제 비용
- 스타터별 정확한 보상 가중치 수치
- 지역 가중치와 타지역 출현률

## 13. 동일 슬롯 교체 UI 계약 v1

카드 보상, 상점, 이벤트에서 네임드를 얻는 기본 성장 행동은 서로 다른 덱 수정 코드를 만들지 않고 `replace-slot-variant` 공용 계획을 사용한다.

계획이 반드시 보여 주는 정보:

- 출처: `reward / shop / event`
- 원본 `rank+suit` 슬롯
- 현재 상태: 순수 카드 또는 현재 네임드 변형
- 교체 후 네임드 변형
- `preservesSlot: true`
- `changesDeckSize: false`
- 취소 가능

잘못된 후보는 계획 자체를 만들지 않는다. 조커, 현재 덱에 없는 슬롯, 이미 장착한 동일 변형은 동일 슬롯 교체 대상이 아니다.

현재 UI 프로토타입에서는 행동 태그 보상 후보를 누르면 `현재 → 교체 후` 확인 패널이 열리며 취소할 수 있다. 실제 적용 버튼은 비활성 상태다. 이유는 로그라이크 시작 덱 장수와 추가/제거 경제가 아직 확정되지 않았기 때문이다. 따라서 이 단계는 **교체 의미와 사용자 확인 흐름만 잠그며 일반 1대1 덱빌더나 진행도 데이터를 수정하지 않는다.**

향후 실제 런 덱이 생기면 같은 계획 객체의 검증 결과를 보상/상점/이벤트 공통 commit 함수가 소비하도록 확장한다.

## 14. 성장 경제 구조 실험 v1 — 제거 vs 동일 슬롯 교체

실전 상점 가격이나 드롭 등급을 정하기 전에, `experiments/m11a-growth-economy.mjs`로 **덱 구조 자체의 가치만 분리**해 측정했다. 실험은 현재 `index.html`의 실제 세트/런 판정을 직접 읽으며, 현재 기본 30장 구조인 `일반 rank+suit 슬롯 29장 + 조커 1장`에서 결정적 4,000 seed의 6장 손패를 비교한다. 조커 제거는 별도 경제축으로 보고 이번 제거 스윕에서 제외한다.

기준 결과:

- 기본 30장: 조합 가능 손패 32.48%, 세트 포함 20.03%, 런 포함 21.88%, 서로 겹치지 않는 2조합 잠재력 0.68%, 손패당 평균 합법 3장 조합 0.551.
- 동일 슬롯 네임드 교체: 덱 크기와 원본 rank+suit 슬롯이 같으므로 위 구조 지표 변화량은 정확히 0. 경제 가치는 구조가 아니라 **네임드 효과와 희소도**에서 나온다.
- 일반 슬롯 1장 제거 평균: 조합 가능률 32.73%로 +0.25%p, 평균 합법 조합 0.563으로 +0.012였지만 2조합 잠재력은 0.55%로 -0.13%p였다.
- 제거 효과는 슬롯별로 크게 달랐다. H10 제거는 조합 가능률 34.73%(+2.25%p), S7 제거는 30.10%(-2.38%p)였다. 즉 주변 슬롯 제거는 남은 구조를 농축할 수 있지만, 중앙 RUN 축 제거는 오히려 덱의 조합성을 무너뜨릴 수 있다.

### M11A 경제 결정

- **제거를 동일 슬롯 교체의 단순 상위 업그레이드로 가격 책정하지 않는다.**
- 동일 슬롯 교체는 기본 성장축으로 유지한다. 덱 구조를 보존하므로 보상 후보 알고리즘과 현재 `replace-slot-variant` 계약에 그대로 맞는다.
- 제거는 `reward` 교체 후보 풀과 섞지 않고 **별도의 희소 성장 행동**으로 둔다. 상점/이벤트 등 명시적인 출처에서 제공하는 방향을 우선한다.
- 제거 확정 UI에는 현재 덱빌더의 숫자/무늬/세트/런 분석을 재사용해 제거 전후 구조 변화를 보여 주고, 핵심 RUN 축 또는 다중 조합 잠재력이 감소하면 경고한다.
- 조커 제거는 일반 슬롯 제거와 같은 가격표를 쓰지 않고 별도 설계 대상으로 남긴다.
- 정확한 골드 비용, 등장 확률, 일반/엘리트/보스별 보상 등급은 이 구조 실험만으로 잠그지 않는다. M12 실전 전투 데이터와 실제 런 경제가 생긴 뒤 확정한다.

이 결정은 ROADMAP의 `카드 제거와 네임드 교체의 경제적 가치 비교`를 닫지만, `보상 희귀도/전투 등급`과 실제 가격 수치는 계속 미확정으로 남긴다.

## 15. 스타터 수치 기준 v1 — 30장 / PURE 기준 구조

M11A 런 초안의 `deckPlan`을 미확정 자리표시자에서 실제 수치 계약으로 승격한다. 아직 이 덱을 로그라이크 전투에 직접 연결하지는 않지만, 이후 런 덱 구현은 아래 기준을 Source of Truth로 사용한다.

### 공통 30장 골격

- 모든 스타터는 **30장**으로 시작한다.
- 정규 카드 슬롯은 **29개**, 조커 슬롯은 **1개**다.
- 정규 29슬롯은 `CORE_IDS.slice(0,29)`를 공통 기준으로 사용한다: `S3,S4,S5,S6,S7,S8,S9,H2,H3,H4,H7,H8,H9,D2,D3,D4,D5,D6,D7,D8,C3,C4,C5,C6,C7,C8,C9,S10,H10`.
- 네임드 정규 카드는 이 29개 원본 rank+suit 슬롯을 **교체**할 뿐 슬롯을 추가하지 않는다. 따라서 스타터마다 SET/RUN 기본 기하를 다르게 주지 않고 카드 효과/보상 성향으로 정체성을 만든다.

### 유랑자 / 수집가 / 회수꾼 / 광대

- 순수 카드: **23장**.
- 네임드 정규: **6장**.
- 네임드 조커: **1장**.
- 총 네임드/효과카드: **7장 = 23.3%**, 순수카드: **23장 = 76.7%**.
- 6개의 네임드 정규는 서로 다른 원본 슬롯을 사용해야 한다. 시작부터 하나의 테마 완성 콤보를 고정 지급하지 않으며 실제 카드 ID 선정은 후속 스타터 조립 단계에서 한다.

### PURE

- 순수 정규: **29장**.
- 기본 와일드 조커: **1장**.
- 네임드/고유 효과카드: **0장**.
- 기본 와일드 조커는 `suit === 'J'`가 제공하는 조합용 와일드 판정만 가진다. `광대왕 조커(J1)`의 고유 효과인 조합 정리 후 즉시 원주인 덱 아래 복귀를 포함해 어떤 네임드 효과도 갖지 않는다. 일반 카드처럼 소모/재순환 흐름을 따른다.
- 이 때문에 PURE도 다른 스타터와 같은 30장/조커 1장 구조를 유지하면서 `효과카드 0장` 정의를 지킨다. 초기 6장 손패의 순수한 SET/RUN 구조 비교에서는 기존 M11A 30장 기준 골격을 그대로 사용할 수 있다.

### 캐릭터 가중치 / 패시브

- 유랑자: `combo 1.7 / cycle 0.9 / extend 0.6 / pressure 0.3`.
- 수집가: `hold 1.8 / sustain 0.8 / pressure 0.4 / status 0.3`.
- 회수꾼: `discard 2.0 / cycle 1.1 / interact 0.7 / control 0.4`.
- 광대: `trick 2.2 / combo 1.0 / interact 0.6 / status 0.4`.
- PURE: 가중치 없음.
- 이 값들은 **보상 후보 랭킹 점수**에만 사용하는 `character-tendency-score-v1`이다. 실제 드롭 확률표가 아니며 0가중치 테마/행동도 후보에서 제외하지 않는다.
- 스타터 직접 전투 패시브는 v1에서 전원 `none`이다. M12 실전 데이터 전에 카드 수치 + 캐릭터 전투 패시브 + 보상 확률을 동시에 조정하는 다중 밸런스 축을 만들지 않는다. 향후 유물/패시브 시스템을 추가하더라도 이 결정과 별도 단계에서 검증한다.
