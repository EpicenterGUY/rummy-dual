# RUMMY//DUEL — Roguelike Master Plan (Working Draft)

Updated: 2026-08-30

이 문서는 RUMMY//DUEL의 로그라이크 확장에 대해 현재까지 논의한 **캐릭터/스타터, 순수카드, 테마군, 지역, 카드 보상, 런 구조**를 한곳에 보존하는 작업용 설계안이다.

중요: 아래 내용은 구현 확정 수치가 아니다. `FINAL CORE 2.0`의 전투 규칙을 바꾸는 문서도 아니다. 향후 플레이테스트와 추가 기획을 거쳐 지역 수, 시작 덱 장수, 보상 확률, 캐릭터 패시브, 카드 희귀도 등을 다시 설계한다.

## 1. 로그라이크의 핵심 방향

- 완성된 테마덱을 고르고 시작하는 구조보다 **스타터가 방향만 제시하고 런 도중 덱이 변하는 구조**를 우선한다.
- 기본 흐름 후보는 `스타터 선택 → 공통 시작 구역 → 지역 분기 → 지역별 카드풀/이벤트 → 중간 보스 → 추가 지역 선택 → 후반 특수구역 → 최종 보스`다.
- 순수 트럼프가 덱의 뼈대이며, 네임드 카드는 숫자/무늬 구조 위에서 규칙을 비튼다.
- 테마군은 서로 섞일 수 있어야 하며, 지역 선택은 특정 테마를 강제하기보다 해당 플레이스타일의 등장 확률을 높인다.
- 같은 스타터라도 런 후반에는 시작과 전혀 다른 혼합덱이 될 수 있어야 한다.

## 2. 캐릭터 / 스타터 방향

캐릭터는 특정 카드군만 사용할 수 있는 클래스가 아니라 **런의 출발 방향**이다.

후보 요소:

- 순수 트럼프 다수 + 해당 성향의 효과카드 소수
- 특정 행동 또는 지역/테마 카드 보상 가중치
- 작은 고유 패시브 또는 시작 유물
- 다른 테마 및 다른 지역 카드 획득은 항상 허용

캐릭터 선택만으로 완성 콤보를 지급하지 않는다. 예를 들어 V-SIGNAL 성향 캐릭터로 시작해도 런 중 ZERO//SIGHT, MAIL//ROUTE, POINT//BLANK 등으로 자유롭게 전환하거나 혼합할 수 있다.

미확정 항목:

- 캐릭터별 시작 덱 장수
- 순수카드/효과카드 비율
- 고유 패시브의 강도
- 보상 가중치 방식
- 캐릭터와 지역의 관계

## 3. PURE — 온리 순수 스타터

`PURE`는 별도 테마 카드군이 아니라 **효과카드 0장으로 시작하는 백지형 스타터/빌드 경로**다.

방향:

- 모든 시작 카드는 효과 없는 순수 트럼프.
- 숫자/무늬 분포는 안정적인 방향을 우선 검토한다.
- 런 중 어떤 카드군으로도 전환 가능하다.
- 끝까지 네임드 카드를 받지 않는 온리 순수덱 클리어도 가능하게 한다.
- 순수덱 지원은 새 전용 카드군보다 유물/패시브/이벤트 등 카드 외부 시스템을 우선 검토한다.
- PURE의 장점은 직접 전투 보너스보다 카드 선택/교체/제거 자유도 쪽에 둔다.

후보 특전은 카드 보상 선택지 +1, 네임드 교체 비용 감소, 제거/슬롯 조정 비용 감소 등이 있으나 아직 확정하지 않는다.

## 4. 순수카드 → 네임드화 성장

로그라이크의 주요 차별점으로 **같은 랭크+무늬 슬롯의 순수카드를 네임드 변형으로 교체/진화**시키는 방식을 우선 검토한다.

예:

`7♠ 순수 카드 → 7♠ 검은 탄환`

또는 동일 7♠ 슬롯의 다른 테마 변형으로 교체한다.

원칙:

- 숫자와 무늬는 보존한다.
- 세트/런 분포를 무너뜨리지 않고 효과 정체성을 성장시킨다.
- 모든 순수카드를 네임드화하는 것이 자동 정답이 되어서는 안 된다.
- 성장 방식은 `교체 / 추가 / 제거` 세 축을 검토한다.
- 교체는 기본 성장 수단, 추가/제거는 더 희소한 수단으로 두는 방향이 유력하다.

## 5. 카드 보상 구조

일반 전투 보상 후보는 기본적으로 **3장 중 1장 선택 + 건너뛰기**를 우선 검토한다.

세 슬롯의 역할을 다르게 두는 안:

1. 현재 빌드 강화 — 현재 덱의 행동과 직접 시너지
2. 확장/새 방향 — 새로운 테마 또는 혼합 빌드의 초동
3. 기반 보강 — 범용 네임드, 순수 슬롯 개선, 숫자/무늬 보정

보상은 `V-SIGNAL 카드가 많다` 같은 단순 테마명 검사만 보기보다 실제 덱 행동 태그를 함께 본다.

예시 행동 태그:

- 새 세트 생성
- 런 생성/확장
- 상대 조합 붙이기
- 회수
- 정비
- 버림패 이용
- 스위치 반환
- 러미
- 상태 부여/해제

따라서 회수 중심 덱에는 V-SIGNAL뿐 아니라 MAIL//ROUTE, POINT//BLANK, SCRAP//SHIFT 등 관련 카드가 새 방향 후보로 나타날 수 있다.

## 6. 새 테마 진입과 보상 단계

새 카드군을 처음 발견했을 때 피니셔만 덜렁 등장하는 문제를 막기 위해 테마 내부 역할 단계를 둔다.

`초동 → 엔진 → 보상 → 피니셔`

- 처음 진입 시 초동/기본 엔진의 출현 가중치를 높인다.
- 실제 덱에 전용 개념 생성 수단이 생기면 중급 엔진을 연다.
- 엔진이 갖춰진 뒤 강한 보상/피니셔가 자연스럽게 등장하도록 한다.
- 별도 `테마 레벨` 자원을 만드는 대신 현재 덱에 실제로 어떤 기능이 있는지 검사하는 방식을 우선한다.

전투 등급별 보상 방향 후보:

- 일반전: 초동 / 기본 엔진 / 범용 / 기반 개선
- 엘리트: 강한 엔진 / 규칙 변형 / 희귀 유물
- 보스: 피니셔 / 시그니처 / 대규모 카드 개조

## 7. 지역 기반 카드풀

`테마군 하나 = 지역 하나`로 고정하지 않는다.

대신 **지역 = 공통 문화/환경 + 서로 어울리는 여러 테마군 + 지역 공용 카드** 구조를 우선 검토한다.

새 카드군을 만들 때도 먼저 지역의 문화, 직업, 갈등, 인프라를 만들고 거기서 여러 집단/테마군이 파생되게 하는 방향이 유력하다.

카드 계층 후보:

`전역 범용 → 지역 공용 → 테마군 → 캐릭터 고유`

지역 공용 카드는 같은 지역의 서로 다른 테마군이 공유하는 행동 축을 지원한다.

## 8. 공통 시작 구역

런 초반은 특정 테마 지역으로 바로 들어가기보다 **공통 구역에서 빌드의 씨앗을 찾는 구조**를 우선한다.

공통 구역 후보 보상:

- 순수카드/슬롯 개선
- 범용 네임드
- 여러 테마의 초동 카드
- 상점
- 이벤트
- 기본 유물

이후 플레이어가 현재 덱의 방향을 보고 지역을 선택한다.

즉 `지역이 빌드를 정한다`보다 **카드가 씨앗을 주고 지역이 그 방향을 밀어준다**는 순서를 우선한다.

## 9. 지역 후보

### NEON//ARC — 네온아크

미디어, 가상 방송, SNS, 광고, 배송, 정보망이 밀집한 초고밀도 상업도시.

현재 연계 테마 후보:

- `V-SIGNAL`
- `MAIL//ROUTE`

향후 해커, 기자, 광고, 데이터 브로커 계열 등을 추가할 수 있다.

주요 행동 성향 후보: 정비 / 회수 / 카드 이동 / 패순환 / 정보 전달.

### RED//ZONE — 레드존

도시전, 용병, 정찰, 돌입전이 이어지는 분쟁구역.

현재 연계 테마:

- `ZERO//SIGHT`
- `POINT//BLANK`

향후 폭파병, 의무병, 용병, 드론 정찰 계열 등을 추가할 수 있다.

주요 행동 성향 후보: 상대 조합 붙이기 / 표적 / 접전 / 고정 / 봉인 / 스위치 압박.

### IRON//GRAVE — 아이언그레이브

폐공장, 고철 산, 버려진 기계와 로봇이 쌓인 산업폐허.

현재 연계 테마 후보:

- `SCRAP//SHIFT`

향후 로봇, 공장, 중장비, 기계공 테마 등을 추가할 수 있다.

주요 행동 성향 후보: 회수 / 소모 / 이동 / 부품화 / 재조립.

### OLD//QUARTER — 올드쿼터

낡은 골목, 사설 탐정, 범죄조직, 암시장, 오래된 상점과 계약이 얽힌 구시가지.

향후 후보:

- 탐정
- 마피아/조직
- 도둑
- 밀수
- 계약/거래

주요 행동 성향 후보: 버림패 / 정보 / 거래 / 방해 / 상대 행동 추적.

### NULL//WARD — 널워드

기록과 지도에서 삭제된 격리구역. 실험실, 이상현상, 변이체와 버려진 시설이 남아 있다.

향후 후보:

- 실험체
- 초능력
- 괴이
- 저주
- 변이

주요 행동 성향 후보: 카드 변형 / 상태 / 위험한 규칙 예외 / 고위험 고보상.

초기부터 갈 수 있는 지역인지 후반 특수구역인지 아직 미정이며, 후반 지역으로 사용하는 안이 유력하다.

## 10. 지역 보상은 확률 가중 방식

한 지역에 들어갔다고 해당 테마만 등장하지 않는다.

예를 들어 네온아크에서는 V-SIGNAL과 MAIL//ROUTE 및 네온아크 공용 카드의 비중이 높아지지만, 범용 카드와 소량의 타지역 카드도 등장할 수 있다.

지역 선택의 의미는 `이 테마를 강제로 한다`가 아니라 **이런 플레이스타일이 잘 나오는 환경으로 간다**에 둔다.

정확한 비율은 미정이다.

## 11. 현재 테마군과 지역 관계

- `V-SIGNAL` — 네온아크 중심 후보. 방송/합방/RAID/회수/러미.
- `MAIL//ROUTE` — 네온아크 중심 후보. 우편 지정/목적지/도착/반송/재배송.
- `ZERO//SIGHT` — 레드존 중심. 표적/관측/정밀 타격.
- `POINT//BLANK` — 레드존 중심. 접전/침투/회수/교대.
- `SCRAP//SHIFT` — 아이언그레이브 중심 후보. 부품/해체/재조립.

기존 테마의 상세 카드 효과는 별도 테마 문서에서 관리한다. 이 문서는 지역/로그라이크에서의 위치를 기록한다.

## 12. 혼합 빌드의 목표 경험

예시 A:

`PURE → 공통 구역에서 ZERO//SIGHT 초동 → 레드존 → 표적/접전 혼합 → 네온아크 → MAIL//ROUTE 획득 → 표적 조합을 목적지로 사용`

예시 B:

`V-SIGNAL 성향 캐릭터 → 네온아크 → RAID/회수 중심 → 아이언그레이브 → SCRAP//SHIFT 획득 → 방송 카드를 부품화하는 혼합덱`

스타터는 목적지가 아니라 출발점이어야 한다.
