# RUMMY//DUEL — Roguelike Starters & Pure Deck Direction

Updated: 2026-09-01

이 문서는 RUMMY//DUEL을 로그라이크/런 기반 구조로 확장할 때의 **캐릭터, 테마 카드군, 순수 트럼프 스타터**에 대한 현재 설계 결정을 보존한다. 시작 덱 30장 구조와 스타터별 순수/네임드 비율은 v1 기준으로 잠그며, 실제 보상 등장 확률·희귀도·런 경제는 플레이테스트로 조정한다.

## 1. 기본 방향

- 로그라이크 시작 선택은 처음부터 완성된 테마 덱을 지급하는 방식보다 **캐릭터/스타터가 플레이 방향을 제시하는 방식**을 우선한다.
- 캐릭터는 특정 카드군만 사용할 수 있게 잠그지 않는다.
- 캐릭터는 초기 효과카드 몇 장, 카드군 가중치, 선택 보상 성향 등으로 방향을 제시한다.
- 런 도중 다른 카드군을 획득해 혼합 빌드로 전환할 수 있어야 한다.
- 순수 트럼프 카드는 효과가 없더라도 세트/런의 숫자·무늬 재료라는 자체 가치가 있으므로 로그라이크에서도 핵심 기반 카드로 유지한다.

## 2. 캐릭터 ↔ 카드군 관계

캐릭터는 카드군과 1:1로 완전히 종속되지 않는다.

예시:

- V-SIGNAL 계열 캐릭터: V-SIGNAL 효과카드 일부 + 방송/회수/세트·런 연결 카드 보상 가중치
- ZERO//SIGHT 계열 캐릭터: 표적/관측 계열 일부 + 손패 유지/상대 조합 활용 카드 보상 가중치
- POINT//BLANK 계열 캐릭터: 접전/침투 일부 + 상대 조합 붙이기/회수 카드 보상 가중치
- 향후 SCRAP//SHIFT 계열 캐릭터: 부품화/해체/재조립 방향의 보상 가중치

캐릭터 선택은 **런의 출발 방향**이지 최종 덱을 결정하는 클래스 잠금이 아니다.

## 3. 일반 캐릭터 스타터 덱 — v1 잠금

유랑자, 수집가, 회수꾼, 광대의 시작 덱은 동일한 30장 골격을 사용한다.

- 정규 슬롯 29 + 조커 1 = **30장**.
- 순수 정규 카드 **23장**.
- 네임드 정규 카드 **6장**.
- 네임드 조커 **1장**.
- 총 네임드/효과카드 **7장(23.3%)**, 순수카드 **23장(76.7%)**.
- 네임드 정규 6장은 서로 다른 rank+suit 슬롯을 교체하며 원본 29슬롯 기하를 보존한다.

목표는 시작부터 테마 콤보가 완성되어 있는 것이 아니라 **테마 방향의 씨앗만 가진 덱**이다. 정확히 어떤 6장의 네임드와 어떤 네임드 조커를 받는지는 후속 스타터 조립 단계에서 정하되, 하나의 테마 완성 콤보를 고정 지급하지 않는다.

## 4. PURE — 온리 순수 스타터

`PURE`는 별도 테마 카드군이 아니라 **효과카드 0장으로 시작하는 백지형 로그라이크 스타터/빌드 경로**다.

### PURE 시작 특징 — v1 잠금

- 시작 덱은 **순수 정규 29 + 기본 와일드 조커 1 = 30장**이다.
- 정규 29슬롯은 `CORE_IDS.slice(0,29)`를 사용한다: S3–S9 + S10, H2–H4/H7–H10, D2–D8, C3–C9.
- 기본 와일드 조커는 조합용 와일드 판정만 있고 네임드가 아니다. 광대왕 조커의 정리 후 즉시 덱 복귀 같은 고유 효과도 없다.
- 따라서 PURE의 시작 네임드/효과카드는 정확히 **0장**이다.
- 초반 전투의 카드 효과 파워는 낮지만 세트/런의 기본 구조를 가장 순수하게 활용한다.
- 런 도중 어떤 카드군의 네임드도 획득 가능하다.
- 특정 카드군으로 갈아타거나 여러 카드군을 섞는 데 가장 자유롭다.

### PURE의 보상 방향

PURE의 장점은 직접 전투 보너스보다 **덱 구축 자유도**에 둔다.

후보:

- 카드 보상 선택지 +1
- 네임드 교체/진화 비용 감소
- 카드 제거 또는 슬롯 교체 비용 감소
- 숫자/무늬 분포를 조정하는 보상 접근성 증가

정확한 특전은 로그라이크 경제 설계 이후 결정한다.

## 5. 끝까지 순수덱 플레이

런 도중 네임드 획득을 거부하고 **끝까지 순수 트럼프만으로 클리어하는 빌드도 가능하게 하는 방향**을 유지한다.

이를 위해 순수덱 전용 테마 카드를 만들기보다는 유물/패시브/런 보너스처럼 카드 외부 시스템을 우선 검토한다.

예시 후보:

- 덱에 효과카드가 없으면 정비 보너스
- 순수카드만으로 만든 조합에 일시 보호
- 순수덱 러미 시 작은 덱순환 보너스

이 보너스는 PURE가 필수 최강 선택지가 되지 않도록 조정한다.

## 6. 순수카드 → 네임드화 성장

로그라이크 성장의 중요한 축으로 **기존 순수 슬롯을 네임드 변형으로 교체/진화**하는 방식을 우선 검토한다.

예:

`7♠ 순수 카드`
→ `7♠ 검은 탄환`
또는
→ 같은 7♠ 슬롯의 다른 테마/네임드 변형

원칙:

- 동일 랭크+무늬 슬롯 구조를 유지한다.
- 네임드화는 숫자·무늬 분포를 그대로 보존하면서 효과만 변화시키는 주요 성장 방식이 될 수 있다.
- 모든 순수카드를 네임드로 바꾸는 것이 자동 정답이 되어서는 안 된다.
- 특정 숫자/무늬 분포를 위해 효과 없는 순수카드를 끝까지 유지하는 선택도 가치가 있어야 한다.

## 7. 로그라이크 런의 기대 성장 흐름

예시:

PURE 시작
→ 초반 ZERO//SIGHT 카드 획득
→ 표적 기반 빌드로 기울기
→ V-SIGNAL 회수 카드 획득
→ 저격 + 방송 혼합 엔진
→ 후반에는 시작과 전혀 다른 개인 덱 완성

또는:

V-SIGNAL 캐릭터 시작
→ 방송 계열 카드 일부 보유
→ POINT//BLANK 침투 카드 보상이 잘 나옴
→ RAID/접전 혼합 덱으로 변화

즉 스타터는 목적지가 아니라 **런마다 다른 덱이 생기게 하는 출발점**이어야 한다.

## 9. 캐릭터 선택 UI / 런 초안 초기화

로그라이크 스타터 선택은 기존 일반전의 `캐릭터 + 테마` 선택과 분리한다. 현재 프로토타입은 유랑자, 수집가, 회수꾼, 광대와 PURE를 출발점으로 보여 주며, 선택 결과는 별도 런 초안에 저장한다.

초안은 공통 시작 구역과 빈 지역 경로, 카드군 하드 잠금 없음에 더해 v1 스타터 수치를 기록한다. 일반 4스타터는 30장 중 순수 23 + 네임드 정규 6 + 네임드 조커 1, PURE는 순수 정규 29 + 기본 와일드 조커 1이다. 직접 전투 패시브는 전원 없음으로 잠그고 기존 캐릭터 `weights`는 보상 후보 랭킹에만 사용한다. 실제 보상 등장 확률은 계속 미확정이며, 이 UI는 현재 일반전 덱을 복사하거나 즉시 로그라이크 전투를 시작하지 않는다.
