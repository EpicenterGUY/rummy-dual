감정사의 발동 위치는 기존 `onDiscardDraw`의 자기 획득 조건을 유지하고 효과문을 명확히 했다. 손에 든 감정사가 다른 획득 카드에 반복 보상을 주는 패시브를 새로 만들지 않는다. 콜라보 신청은 해당 행동을 포함한 두 조합 종류의 사용 이력을 검사한다. 이미 두 종류를 모두 사용한 뒤 이 카드를 사용하는 경우에도 카드당 턴 1회 조건 안에서 발동한다.

## 기본 획득과 선택

`basicDiscardChoices()`는 맨 위 기본 선택, 장물아비의 두 번째 카드, 사형선고의 위 3장 내 정확한 목표, 암시장의 두 번째 카드를 하나의 후보 목록으로 만든다. 같은 카드에 무료 선택과 암시장 유료 선택이 겹치면 무료 선택을 사용한다. 암시장만으로 두 번째 카드를 선택할 때에만 원래 맨 위 카드가 현재 소유자의 소모패로 이동한다.

플레이어와 AI 모두 `acquireBasicCard()`를 거친다. 선택한 카드·깊이·소모할 맨 위 카드가 현재 후보와 일치하는지 다시 검사한 뒤 정확히 1장만 가져온다. 획득 성공 시 턴 토큰으로 중복 획득을 막고 `onAcquire`를 1회 발행한다. 취소·오래된 선택·실패에는 카드를 옮기거나 획득권을 쓰지 않는다. 카드의 현재 소유자는 획득자로 바뀌고 원주인은 유지한다.

독점상 보정은 성공한 개인 덱 **기본 획득**에만 붙는다. 효과 드로우·러미 보충·정비로는 제한을 소비하거나 보정을 받지 않는다. 순환은 남은 손패 1장을 아래로 보내고 1장 받는 교환이며, 기본 정비권을 소비하거나 손패를 추가 증가시키지 않는다. 획득원이 없으면 기존 순환 정체 처리로 넘어간다.

AI는 같은 후보들 중 조합에 도움이 되는 카드를 평가한다. 상대 턴에 미끼의 원주인 선택창이 열리면 기존 진행을 멈추고, 선택 후 획득을 반복하지 않고 행동 단계부터 재개한다. 신규 상태 전체의 전략 가중치나 인간 실전 밸런스가 확정되었다는 뜻은 아니다.

## 예약 처리

- 기존 회수/재배치 완료 예약에 조합 한정 붙이기, 다음 공개, 다음 실제 반환 조건을 추가했다.
- 역바이럴은 반환 가능 여부와 턴 제한 검사를 통과한 뒤 위력 상태를 소비하기 전에 장전 10을 부여한다. 실패와 같은 런 연속 연장은 소비하지 않는다. 무가산 반환이면 예약은 해결되지만 장전은 다음 위력 가산 반환까지 남는다.
- 역바이럴의 같은 카드·같은 상대 턴 반응은 한 번이며, 다음 턴에 다시 반응해도 미해결 예약을 중첩하거나 갱신하지 않는다. 문구에 턴 만료가 없으므로 다음 실제 반환이나 전투 종료까지 유지한다.
- ON AIR는 실제 붙이기의 반환·네임드 효과를 마친 뒤 장전을 받는다. 해당 반환의 위력을 소급 변경하지 않는다. 원본 카드가 회수되어도 대상 런이 살아 있으면 유지하지만, 대상 런의 정리·분할·합병·전체 재순환으로 취소한다.
- 100만 구독은 새 조합/붙이기 완료 시 그 조합에 남은 내 사용 카드 중 선택 순서의 첫 장에 두 상태를 함께 준다. 공개 조합 사이 이동·회수·보존·귀환은 새 공개로 보지 않는다. 러미 직전 사용 카드가 원주인에게 귀환했더라도 예약은 그 카드를 사용한 발동자에게 남는다.
- 모든 일치 예약을 먼저 제거하고 해결해 재진입 중복을 막는다. 승리·패배·교착 무승부에 큐를 비우고 종료 뒤 새 예약을 거부한다.

HUD는 예약 종류와 지정 조합 번호를 표시하고, 독점상으로 막힌 버림패 버튼을 비활성화한다. 남아 있던 퀵 리로드·쌍면 조커의 보호막 안내도 실제 불굴 보상으로 맞췄다.
