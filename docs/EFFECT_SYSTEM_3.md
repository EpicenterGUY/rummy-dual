사용자가 승인한 범위는 코어 유지, 공용 상태 확장, 공용 카드 전수 재검토와 테마 재설계다. 이 문서에서 **구현**과 **후속 설계**를 구분한다. 이전 카드 효과와 충돌하면 아래 첫 묶음의 명세를 우선한다. 카드 ID, 슬롯, 해금 기록은 유지한다.

## 유지하는 코어

3 CORE × 60, 공개 조합 최대 3개, 턴당 정확히 3장 새 조합 최대 2개, 실제 반환 턴당 1회, 기존 SET/RUN·BURST/CHAIN·RUMMY·상대 공개 조합 공유·회수 재사용 제한을 유지한다. 정리·회수·이동·카드 반환은 새 조합 생성 횟수를 환불하지 않는다. 같은 런의 당턴 추가 연장은 실제 반환이 아니므로 아래 반환 상태를 다시 소비하지 않는다.

| 상태 | 대상 | 중첩 및 처리 |
|---|---|---|
| 취약 | 플레이어 | 기존 다음 폭발 25% 증폭 후 제거 유지 |

상태 수치는 음수가 아닌 정수다. NaN/Infinity는 저장하지 않는다. 장전·감쇠·과열은 이번 묶음에서 플레이어에만 부여한다. 조합/카드 범위의 같은 상태는 아직 지원하지 않는다.

### 반환 순서

1. 스위치 소유 및 턴당 반환 제한 검사. 실패하면 상태를 소비하지 않는다.
2. 기존 카드 효과를 해결해 반환 위력을 계산한다.
3. 무가산 반환이면 장전·감쇠·과열을 보존한다.
4. 일반 반환이면 `max(0, 행동 위력 + 장전 + 과열 − 감쇠)`를 누적한다. 세 상태 전량 소모. 감쇠는 기존 누적 폭탄을 깎지 않는다.
5. 방향 변경 및 반환 횟수 소비.
6. 과열 반동을 일반 피해 경로로 처리한다. 보호막/불굴로 방어 가능하며, 코어가 깨지면 기존 폭탄 초기화가 우선한다. 반동으로 폭탄이 사라져도 추가 반환권은 생기지 않는다.

초안의 ‘감쇠는 기본 위력만 감소’는 카드 보너스와 분리되지 않은 현재 행동 위력 파이프라인을 고려해 **이번 반환의 전체 추가 위력**으로 명확히 한다. 과열은 반복 영구 강화가 아니라 한 번 소비하는 상태다.

### 귀환의 목적지 우선순위

기존 명시적 보존 → 광대왕 덱 복귀/대역 배우 기존 복귀 → 소모될 경우 귀환 → 소모패. 앞선 대체가 적용되면 귀환은 소비하지 않는다. 회수/탈취/이동에는 귀환이 발동하지 않는다. 일반 귀환에는 onRecover와 회수 횟수 보상을 발행하지 않는다. 이동 후 원주인 손패가 목적지여도 카드 한 장은 한 영역에만 존재한다.

### 유예 호환

안전핀의 `graceArmed`는 기존 경로 호환용으로 유지하고 공식 유예와 함께 동기화한다. 상태 해제는 준비도 해제하지만 해당 폭탄 사이클의 사용권은 복구하지 않는다. 폭탄 초기화는 양쪽 유예와 준비를 모두 제거한다.

## 후속 효과 엔진/카드 작업

- 공용 행동: 순환, 보존, 회수, 재배치(기존 이동의 한국어 이름), 예약, 대체. 재배치와 이동을 서로 다른 중복 행동으로 만들지 않는다.
- 선언형 효과: 조건 → 대상 → 행동 → 후속 → 제한. 대상 및 비용 검증 후 확정하고 완료 이벤트는 1회만 발행한다.
- 특이효과 우선순위: 이중 숫자·숫자 승계 → 합법 조합 간 교환 → 분할/합병 → 제한적 소유권·덱 침투 → 일시적 규칙 변경.
- 예약은 성공한 이벤트에만 반응하고 카드 UID/발동자/만료/남은 횟수를 저장한다. 발동 전 제거해 자기 재귀를 방지한다.
- 공용 A~K 52슬롯을 기본/조작/반응/규칙변형/고유효과로 전수 재설계한다. 20~25% 고유효과는 목표 비율이며 단순 이름만 달리해 채우지 않는다.
- V-SIGNAL은 공용 회수·재등장, ZERO-SIGHT는 표식·정밀 조건, POINT-BLANK는 같은 조합의 혼합 소유·교대, SEASON-BLOOM은 계절 전환·재배치로 재설계한다.
- 이후 실전 밸런스와 AI 가치 평가를 갱신한다. 기존 평가 가중치를 이번 상태의 최적 전략이라고 주장하지 않는다.
