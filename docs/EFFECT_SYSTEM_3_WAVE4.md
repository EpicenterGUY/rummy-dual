## 완료 반응의 계약

`onHeal`은 회복으로 HP가 실제 증가했을 때만 발행한다. `amount`는 내부 회복 단위가 아니라 화면에 표시하는 실제 HP이며 과잉 회복은 포함하지 않는다. 수혈은 자기 턴이고 공개된 카드일 때만 반응한다. 절반을 내림해 0이면 턴 기회를 소비하지 않는다. 상대 보드에 있는 자신의 수혈도 공개 카드로 인정한다.

기생충은 공용 `onAttach` 완료 패킷의 실제 반환 여부를 읽는다. 상대가 제어하는 보드에서 그 상대가 반환해야 하며, 자신의 보드에 상대가 붙이는 경우는 해당하지 않는다. 같은 런 연속 연장은 실제 반환이 아니고, 중복 완료 패킷에도 카드별 턴 게이트로 한 번만 획득한다. 획득한 장전은 공용 상태이므로 이후 기생충이 정리되어도 남는다.

기존 감쇠를 소비하는 염상 스트리머는 합법 반환 행동에서만 사용 효과를 처리한다. 실패한 붙이기나 비반환 행동은 감쇠를 소비하지 않는다. 봉인과 회수 재사용 가드는 기존 엔진을 따른다.

탄창 비우기의 과열 16은 반환 위력에 16을 더하고 반동 일반 피해 8을 발생시킨다. 동시에 얻은 불굴 8은 보호막을 통과하는 양수 반동 피해에 소비된다. 보호막이 반동 전부를 막으면 불굴은 다음 피해까지 남는다. 이는 기존 공용 피해 순서의 결과이며 별도 면제나 반환권을 추가하지 않는다.
