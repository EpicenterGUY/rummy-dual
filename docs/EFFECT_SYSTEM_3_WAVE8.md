## 실제 수치 기록과 복제

`runEffectAction()`에 네임드 출처와 행동 기록을 연결했다. 허용하는 원본은 **실제로 해결된 회복·보호막·독립 누적 위력 증가**다. 출처 UID/이름, 발동자, 종류, 완료량, 복제 여부를 기록한다. 회복/보호막은 내부 입력 단위가 4배 환산되므로 기록에는 화면의 HP 단위를 사용하고 복제 입력에서 한 번만 되돌린다. 예를 들어 실제 보호막 32의 복제는 16이다.

드로우, 상태 부여, 비용, 자해, 회수/재배치, 직접 반환과 반환에 합쳐질 예정 보너스는 복제 원본이 아니다. 필드·재생 등 출처가 네임드가 아닌 수치도 원본으로 기록하지 않는다. 복제 결과는 `copied:true`로 표시해 재귀 함수와 잔향이 다시 복제하지 않는다.

새 조합/붙이기마다 별도 기록을 사용한다. 실제 카드 해결 순서대로 원본을 추가하고 재귀 함수가 도달한 시점의 완료 기록만 후보로 고정한다. 뒤에 해결될 카드, 이전 행동, 상대 네임드, 자기 자신과 복제본은 후보에서 빠진다. 후보가 여러 개면 하나를 고르는 동안 행동 완료를 기다린다. 후보 하나 또는 CPU는 즉시 처리한다.

온기의 대상 선택 뒤 회복이나 RAID가 회수한 구급차의 회복 반응도 원래 행동에 기록된다. 선택창을 재개하면 기존 기록과 해결 위치를 이어 가며 원효과와 복제를 재실행하지 않는다. 중첩된 다른 배치 행동은 독립 기록을 사용한다. 오래된 전투/턴의 선택과 같은 선택 콜백의 재호출은 효과를 다시 적용하지 않는다.

## 잔향의 수명

- 카드 상태 `echo`, 비중첩 1. 유한한 양의 정수 부여만 허용한다.
- 다음 실제 네임드 수치 행동 하나가 양수로 해결되면 잔향을 먼저 제거한 뒤, 실제 완료량의 절반을 내림해 적용한다.
- 원효과가 0인 회복, 봉인·반응 침묵·조건 불충족·대상 없음에서는 잔향이 남는다. 실제 원효과가 1이면 잔향은 소모하고 절반 0의 복제 실행/기록은 생략한다.
- 이미 해결된 효과에 잔향을 부여해도 과거 효과가 재실행되지 않는다. 다음 실제 수치 효과까지 기다린다.
- 침묵은 진입 사용 효과를 멈추지 않으므로 그 효과의 실제 수치는 잔향으로 복제할 수 있다. 반응 효과는 침묵이 풀려야 발동한다.
- 복제 회복도 실제 회복이다. 수혈·심장왕 같은 기존 반응은 자신의 턴당 제한과 상한을 계속 적용한다.

러미를 만든 카드가 조합 정리 중 귀환으로 원주인에게 돌아가더라도, 이미 등록된 러미 수치 효과와 잔향은 그 카드를 사용한 발동자에게 적용한다. 카드의 현재 제어자 변경 때문에 다른 쪽으로 회복이 이동하거나 잔향을 놓치지 않는다.

## 선택과 보존

복사기의 후보는 같은 조합에 실제로 있는 내 다른 네임드다. 이미 공개돼 있던 카드와 다른 테마도 후보이며, 순수 카드와 상대 제어 카드는 제외한다. 여러 후보면 필수 선택이며 실제 해결을 한 번만 재개한다. 뒤에 해결될 보호구를 고르면 이번 보호막에 잔향이 적용되고, 이미 해결된 보호구를 고르면 잔향이 다음 효과까지 남는다.

기념 방송은 러미 재충전 후 새 손패에서 네임드를 고른다. 마지막 웃음이 함께 발동하면 추가 획득과 덱 아래 보내기를 먼저 끝낸 뒤 남은 새 손패를 기준으로 고른다. 후보가 하나여도 부여하지 않기를 선택할 수 있고, 후보가 없으면 바로 진행한다. 선택 또는 건너뛰기 이후에 러미의 턴 종료를 한 번만 수행한다.

24시간 내구방송은 정리 직전에 보존할 카드 1장을 고른다. 현재 내 제어 카드면 순수 카드·다른 테마·원주인이 상대인 카드도 후보이며, 보존은 현재 제어자 손패로 보낸다. 명시적 보존을 귀환보다 먼저 처리하고 회수 이벤트를 만들지 않는다.

보존한 카드 자체에 `echoOnNextPlacement` 예약을 남긴다. 아직 잔향을 부여한 상태가 아니므로 손패 반응이나 다른 카드의 배치로 소모되지 않는다. 해당 카드의 합법적인 손패→공개 배치가 성공하면 예약을 먼저 지우고 진입 효과 전에 잔향을 부여한다. 실패/취소한 배치에는 예약이 남고, 이미 잔향이 있으면 비중첩 1을 유지한다. 턴 만료 없이 다음 배치까지 기다리며 승리·패배·교착 무승부에서 모든 카드 영역의 예약을 제거한다.

카드 면에는 활성 잔향 또는 다음 배치 잔향 예약을 표시하고 상세에서 둘을 구분한다. CPU는 같은 후보와 실행 경로를 사용하며, 잔향이 없는 수치 효과 카드를 우선한다. 재귀 함수는 현재 회복 가능한 양·보호막·스위치 방향을 반영한 간단한 평가로 선택한다. 도감 경향과 그 변경에 따른 결정적 보상 후보 회귀도 동기화했다. 이 평가는 실전 밸런스 검증을 마친 최적 전략은 아니다.
