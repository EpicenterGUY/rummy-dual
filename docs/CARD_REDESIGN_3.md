기준: PR #35의 c7b8286. 이 파일은 design/cards-v3.json에서 생성한다.

기존 122종을 모두 검토했다. 첫 개편 7종과 두 번째 16종을 포함해 69종을 재설계하고 53종은 고유한 기능을 유지한다. 기존 카드 중 괴짜형은 25종(20.5%)이다. **구현 대기 효과는 현재 게임에 적용되지 않았다.**

현재 PR의 적용 범위는 개편 23종이며, 기존 카드 추가 46종과 신규 SEASON-BLOOM 24종은 설계 완료·구현 대기다. 카드군 전체 개편 완료는 모든 예정 카드의 구현·선택 UI·AI·혼합 회귀를 마쳤을 때만 선언한다.
