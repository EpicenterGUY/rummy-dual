# RUMMY//DUEL — Theme Groups Canonical Draft

Updated: 2026-09-01

이 문서는 현재 확정된 정식 테마군의 설계 방향을 보존한다. 실제 수치와 개별 카드 문구는 플레이테스트와 M8 효과 엔진 안정화에 따라 조정할 수 있지만, 아래의 **테마 정체성·전용 개념·공용 카드와의 연결 원칙**은 현재 최종 설계 기준으로 취급한다.

## 공통 설계 원칙

- 테마군은 덱 하나를 강제하는 폐쇄형 묶음이 아니라 플레이스타일을 제공하는 모듈로 설계한다.
- 전용 개념은 허용하지만 별도 전용 자원을 남발하지 않는다.
- 전용 개념을 생성하는 초동 카드를 충분히 배치해 패말림을 줄인다.
- 전용 개념을 만든 뒤 실제 보상을 받는 카드는 가능하면 **어느 카드군의 카드라도** 사용할 수 있게 한다.
- 조건은 `이 테마 카드가 2장 이상` 같은 이름 검사보다 세트, 런, 붙이기, 회수, 정비, 버리기, 스위치 반환, 러미 등 실제 게임 행동을 우선한다.
- 직접 누적 위력 +X 효과는 소수만 사용한다. 현재 전투 스케일은 버스트 +24, 체인 +10/+15/+20/+25, 코어 60을 기준으로 한다.
- 기본 상태인 취약·봉인·고정·보호·재생을 적극 재사용하고, 테마 전용 상태가 공용 엔진을 불필요하게 복제하지 않게 한다.

# V-SIGNAL

## 정체성

버튜버 / 가상 방송 콘셉트의 연쇄 콤보 테마.

**방송 시작 → 합방 → RAID → 회수/방송 종료 → 앵콜/재방송 → 러미** 흐름을 세트·런·상대 조합 붙이기·회수·정비·스위치로 표현한다.

### 잠금된 방향

- `HYPE` 카운터는 사용하지 않는다.
- V-SIGNAL 전용 자원을 만들지 않는다.
- 순수 V-SIGNAL은 자연스럽게 서로 연결되지만, 효과 조건 대부분은 공용 행동을 참조한다.
- 다른 회수/세트/런/스위치/러미 카드군과 혼합 가능한 오픈형 테마다.

### 수트 역할

- ♠ 화제성 / 염상 / 스위치 압박
- ♥ 팬덤 / 회수 / 재사용 / 러미
- ♦ 합방 / 세트 / 조합 보호
- ♣ 방송 진행 / 런 / RAID / 필드 조작

## 현재 정식 후보 카드 풀

### ♠
- A♠ `초방송사고` — 스위치가 자신을 향할 때 방어, 성공 반환 시 소형 추가 위력.
- 5♠ `악질 클립` — 앞선 네임드 효과와 연계한 추가 위력 또는 상대 조합 봉인.
- 7♠ `실시간 논란` — 상대의 직전 회수 행동에 반응하는 압박.
- 9♠ `역바이럴` — 상대가 내 공개 조합을 이용한 뒤 충전되는 반격.
- Q♠ `염상 스트리머` — 높은 누적 위력에서 취약 부여.
- K♠ `BAN 직전` — 높은 누적 위력에서 +16급 피니시 보정.

### ♥
- A♥ `첫 방송` — 새 조합 생성 시 무료 정비.
- 3♥ `ASMR` — 조합 진입 시 보호막, 스위치가 자신을 향하면 강화.
- 5♥ `앙코르` — 이 카드를 회수한 턴에도 한 번, 회수한 조합과 다른 합법적인 공개 조합의 버스트/체인 반환 재료로 다시 사용할 수 있다.
- 7♥ `팬 서비스` — 양측 카드가 섞인 공개 조합 활용 시 회복/보호막.
- 10♥ `기념 방송` — 이 카드로 러미하면 재생 + 보호막.
- K♥ `100만 구독` — 러미 후 첫 조합 카드에 보호/획득 보조.

### ♦
- 2♦ `신인 2기생` — 새 3장 세트 생성 시 무료 정비.
- 3♦ `3인 합방` — 정확히 3장 세트에 보호 부여.
- 4♦ `전원 집합!` — 이 카드가 들어간 SET을 내가 BURST로 완성해 정리할 때, 그 SET에서 내가 제어하는 카드 1장을 손패로 보존할 수 있다. 보존한 카드는 이번 턴 사용할 수 없다.
- 6♦ `슈퍼챗` — 해당 조합을 상대가 이용하면 카드 획득.
- J♦ `매니저` — 봉인/고정 제거 또는 보호 부여.
- K♦ `전설의 아이돌` — 버스트 후 후속 자원 또는 방어를 선택.

### ♣
- A♣ `ON AIR` — 새 런의 체인을 1부터 시작시키는 장기 런 스타터.
- 4♣ `게임 방송` — 낮은 체인의 런 연장 시 무료 정비.
- 6♣ `RAID` — 상대 조합에 붙은 뒤 자신의 다른 공개 카드 무료 회수.
- 8♣ `콜라보 신청` — 같은 턴 세트↔런 교차 플레이에 카드 획득.
- J♣ `천재 편집자` — 자신의 공개 카드를 합법적인 다른 조합으로 이동.
- K♣ `24시간 내구방송` — 이 카드가 들어간 체인 4 이상 RUN을 내가 완주할 때, 그 RUN에서 내가 제어하는 카드 1장을 손패로 보존할 수 있다. 보존한 카드는 이번 턴 사용할 수 없다.

# ZERO-SIGHT

## 정체성

저격수 / 관측 / 준비 / 정밀 타격 테마.

빠른 연속 공격보다 **표적 설정 → 정보/패순환 → 상대 행동 제약 → 정확한 반환**을 중시한다.

## 전용 개념 — 표적

- 자신의 효과로 공개 조합 하나를 `표적`으로 지정한다.
- 기본적으로 자신이 유지하는 표적은 1개.
- 새 표적을 지정하면 기존 표적은 해제한다.
- 표적 조합이 정리되면 표적도 사라진다.
- **표적을 이용해 붙이거나 반환하는 카드는 ZERO-SIGHT일 필요가 없다.**
- 표적 생성 카드 자체에도 정비/보호/덱 조작 등 작은 기본값을 붙여 후반 패말림을 줄인다.

## 현재 정식 후보 18장

- A♣ `관측수` — 조합을 표적으로 지정 + 무료 정비.
- 2♣ `스코프 조정` — 표적 이동, 이동할 곳이 없으면 패순환.
- 2♦ `거리측정기` — 표적 지정/변경 시 덱 위 3장 정렬.
- 3♥ `호흡 조절` — 표적 유지 후 충전, 사용 시 보호막 + 정비.
- 4♠ `제압 사격` — 상대 표적 조합에 붙어 봉인 또는 고정.
- 4♥ `위장망` — 자신의 카드가 든 조합을 표적으로 만들며 보호.
- 5♣ `사각지대` — 자신의 카드가 들어간 상대 조합으로 표적 이동 + 회수 연계 정비.
- 6♦ `탄도 계산` — 표적을 이용한 반환에서 코어 파괴까지 부족한 값을 최대 +12 보정.
- 6♣ `관측 기록` — 표적 장기 유지 후 처음 붙는 자신의 카드에 패순환 보상.
- 7♠ `철갑탄` — 상대 표적 조합 반환 +10, 보호 제거 대응.
- 7♥ `안전거리` — 표적 조합에서 자신의 카드가 회수되면 보호막.
- 8♣ `관측 교대` — 표적 조합에서 회수 후 다른 조합으로 표적 이전.
- 8♦ `예비 탄창` — 표적 조합 확장 시 다음 획득 후보를 미리 본다.
- 9♠ `역추적` — 상대가 표적 조합으로 반환하면 충전, 다음 반환 +12.
- 10♠ `장거리 사격` — 손에서 2턴 준비 후 표적 반환 +16.
- J♣ `관측 드론` — 상대가 새 조합을 만들면 표적 자동 이전 가능 + 정비.
- Q♠ `데드 앵글` — 상대가 표적 조합을 회수/이동하면 취약 및 아군 카드 보호.
- K♠ `ONE SHOT` — 누적 50+에서 상대 표적 조합 반환 +18 후 표적 해제, 실패 시 자기 봉인 리스크.

## ZERO-SIGHT 구현 체크

- [x] 표적 메타데이터 구현 잠금: 공식 상태와 분리된 조합 메타데이터로 관리하며, 각 플레이어는 독립적으로 1개만 유지한다. 새 표적 지정 시 자신의 기존 표적만 해제하고, `onRetire`는 정리 직전 표적 정보를 관측한 뒤 실제 제거 단계에서 표적을 소거한다. 일반/타 테마 카드의 붙이기 합법성은 표적 여부로 제한하지 않는다.
- [x] 공개 조합 단위 `표적` 메타데이터 설계
- [x] 표적 1개 제한 / 이전 / 조합 정리 시 해제 처리
- [x] 표적 반응 이벤트 잠금: `onTargetSet` / `onTargetClear` / `onTargetMeldChange` / `onMeldMove`; `onRecover` / `onAttach` / `onRetire`에는 당시 `targetedBy` 스냅샷을 포함하고 `onMeldCreate`는 새 조합 생성 반응에 그대로 사용
- [x] 일반 카드가 표적 조합을 이용해도 테마 효과가 발동하도록 이벤트 설계 — 카드군 검사 없이 `targetedBy` 스냅샷과 `onTargetMeldChange`를 공용 행동에서 발생
- [x] 손에서 턴 경과 충전 상태를 카드 단위 `handPrep` 마커로 구현
  - 손에 남긴 자신의 턴 종료마다 준비 +1. 상대 턴 경과만으로는 증가하지 않는다.
  - 새로 뽑기/버림패 획득/회수/효과 반환/정리 보존으로 손에 들어오면 준비는 0부터 다시 시작한다.
  - 조합 사용·붙이기·버리기·정비 등으로 손을 떠날 때 준비값은 즉시 초기화하되, 그 행동의 네임드 효과 해석 동안에는 `preparedTurnsAtUse()`가 직전 값을 읽을 수 있다.
  - 준비는 공식 상태 5종이나 별도 전용 자원이 아니라 카드 단위 메타데이터이며, 손을 떠난 뒤 다음 행동까지 축적값을 보존하지 않는다.
- [ ] 코어+보호막 부족분 계산 공통 액션 추가 검토
- [x] 표적 조합 회수/이동/새 조합 생성 반응 이벤트 정리 — `onTargetSet` / `onTargetClear` / `onTargetMeldChange` / `onMeldMove` 및 `targetedBy` 스냅샷을 실행 회귀로 잠금
- [x] 표적 없이 잡힌 스타터의 대체 패순환 처리 — `관측수`는 사용한 조합 자체를 표적으로 지정해 무표적 초동을 열고, `스코프 조정`은 표적/이전 목적지가 없으면 남은 손패 1장을 정확히 골라 덱 아래로 보내고 1장 뽑는다.
- [x] 첫 라이브 스타터 구현 — A♣ `관측수` / 2♣ `스코프 조정`; 둘 다 전용 자원 없이 표적·공용 패순환만 사용하며 전체 1클리어부터 오픈형 ZERO-SIGHT 빌드에 편성
- [x] ZERO-SIGHT ↔ 일반/V-SIGNAL/POINT-BLANK 혼합 회귀 테스트 — 표적 조합은 카드의 `themeId`와 무관하게 일반 붙이기/회수/정리 이벤트를 내보내며, V-SIGNAL 회수 예외와 보존 및 POINT-BLANK 정체성 카드가 같은 공개 조합에서 공존함을 실행 검증

# POINT-BLANK

## 정체성

근접 총격 / 돌입 / 교대 / 난전 테마.

상대 공개 조합 안에 자신의 카드를 밀어 넣고 **접전 생성 → 회수/이동/교대 → 다시 돌입 → 근거리 피니시**로 이어간다.

## 전용 개념 — 접전

- 자신의 효과로 상대 공개 조합 하나를 `접전`으로 지정한다.
- 기본적으로 자신이 유지하는 접전은 1개.
- 새로운 접전을 지정하면 기존 접전은 해제한다.
- 접전 조합에 자신의 카드가 하나 이상 있으면 안정적으로 유지된다.
- 자신의 카드가 모두 빠졌다면 다음 자신의 턴 종료 시 해제한다.
- **접전에 들어가는 카드는 POINT-BLANK일 필요가 없다.** V-SIGNAL RAID나 일반 붙이기 카드도 접전 엔진의 재료가 된다.

## 현재 정식 후보 18장

- A♣ `돌입 명령` — 상대 조합 접전 지정, 이미 접전이면 무료 정비.
- A♥ `브리치 실드` — 새 접전 지정 시 보호막, 이미 자신의 카드가 있으면 강화.
- 2♣ `슬라이드 스텝` — 자신의 카드가 상대 조합에 붙을 때 접전 이전 + 정비.
- 2♥ `사이드암` — 상대 조합에서 회수 시 소모패 전환을 선택해 2장 뽑고 1장 버리기.
- 3♠ `플래시뱅` — 접전 조합에 봉인 또는 고정.
- 4♠ `벅샷` — 접전 반환 +8, 같은 조합에 자신의 다른 카드가 있으면 +12.
- 4♦ `크로스파이어` — 접전 세트와 자신의 세트를 연결, 버스트 시 카드 획득.
- 5♣ `문 걷어차기` — 처음 접전에 붙인 뒤 자신의 다른 공개 카드 무료 회수.
- 6♦ `탄창 교체` — 붙이기/회수/버리기/정비 중 서로 다른 2개 수행 시 2장 뽑고 1장 덱 아래.
- 6♥ `응급 후퇴` — 스위치가 자신을 향할 때 접전 카드 무료 회수 + 보호막 16.
- 7♥ `엄폐 교대` — 접전의 내 카드가 상대 효과의 직접 대상이 될 때 턴당 1회, 같은 효과가 합법적으로 겨냥할 수 있는 다른 내 카드로 대상을 교대. 대체 대상이 없으면 보호막 12를 얻고 원래 효과는 계속 해결.
- 8♠ `영거리 사격` — 접전에 자신의 카드 2장 이상이면 반환 +14 후 자신의 카드 1장 소모.
- 8♣ `백도어` — 상대 런 접전과 자신의 다른 런 사이 카드 이동.
- 9♣ `룸 클리어` — 접전 카드 하나 회수 + 다른 하나를 합법적인 다른 조합으로 이동.
- 10♥ `아드레날린` — 접전 반환 시 보호막, 같은 턴 회수까지 했다면 후속 방어.
- J♦ `퀵 리로드` — 접전에서 이 카드를 회수하면, 이번 턴 이미 새 조합을 만들었어도 이 카드를 포함하는 새 3장 세트/런을 1회 추가 생성. 반환 재료 제한은 유지. *(기본 규칙이 회수 카드의 첫 새 조합 사용을 이미 허용하므로 효과를 비중복 형태로 수정)*
- Q♣ `돌입대장` — 다음에 접전에 붙는 **아무 카드**에게 보호/정비/무료 회수 중 하나 부여.
- K♠ `탄창 비우기` — 접전 붙이기 + 회수 + 버리기/정비를 모두 수행한 턴의 반환 +16 + 카드 획득.

## POINT-BLANK 구현 체크

- [x] 상대 공개 조합 단위 `접전` 메타데이터 설계 — 공식 상태/표적과 분리된 `themeMeta.pointBlank`에서 접전 소유자·지정 턴·지연 해제 시점을 관리
- [x] 접전 1개 제한 / 이전 / 아군 카드 부재 시 지연 해제 처리 — 각 플레이어는 상대 공개 조합 1개만 접전으로 유지하고, 자신의 카드가 0장이 되면 다음 자기 턴 종료 해제를 예약하되 재돌입하면 예약 취소
- [x] 일반 카드가 접전 조합에 붙어도 테마 엔진이 인식하도록 이벤트 설계 — 붙이기/회수/이동은 카드군 검사 없이 `refreshPointBlankClashMeld`와 `onClashMeldChange`를 거쳐 접전 유지·해제 상태를 갱신
- [x] 무료 회수와 기본 회수 횟수의 구분을 데이터로 명확화 — `recoveryAccess = { free, reason, consumesBasic }`을 공용 판정으로 사용하고 `onRecover` 패킷에도 같은 구분을 노출
- [x] 이동 효과는 이동 자체로 버스트/체인/스위치 반환을 발생시키지 않는 기본 원칙 검증 — `onMeldMove`가 전투 중립 계약을 명시하고 공용 이동 함수는 공개 조합/CHAIN/표적·접전 메타데이터만 갱신
- [x] 회수 카드를 추가 새 조합 재료로만 허용하는 `퀵 리로드` 예외 처리 — 접전 회수 시 카드 단위·현재 턴 토큰으로 추가 새 조합 1회를 허용하며 반환 재사용 예외는 부여하지 않음
- [x] 접전에서 적대적 대상 교체/보호막 fallback 처리 — H7 변형 `엄폐 교대`는 카드 소유자 기준 접전을 확인해 턴당 1회 합법 대체 대상으로 교대하고, 대체 불가 시 보호막 12 후 원래 효과를 계속 해결
- [x] POINT-BLANK ↔ 일반/V-SIGNAL/ZERO-SIGHT 혼합 회귀 테스트 — 표적+접전 공존, 일반/타 테마 카드의 접전 이동·적대 대상 교대, 이동의 전투 중립을 실행 검증

# 세 테마 간 혼합 설계 기준

- V-SIGNAL `RAID`로 상대 조합에 침투하면 POINT-BLANK 접전의 실제 재료로 사용할 수 있다.
- ZERO-SIGHT 표적은 POINT-BLANK 접전과 같은 조합에 동시에 존재할 수 있다.
- ZERO-SIGHT의 `표적에 처음 붙는 자신의 카드` 보상은 V-SIGNAL, POINT-BLANK, 일반 네임드를 가리지 않는다.
- POINT-BLANK `돌입대장`의 강화 대상 역시 테마를 가리지 않는다.
- 회수 효과는 V-SIGNAL 앙코르와 POINT-BLANK 퀵 리로드처럼 서로 다른 예외를 만들 수 있으나, 기본 회수 후 동일 턴 버스트/체인 재사용 금지는 명시적 예외가 없으면 유지한다.
- 세 테마를 섞었을 때 한 행동에서 여러 반응 효과가 연쇄될 수 있으므로 트리거 순서/턴당 1회/무료 행동 횟수를 구현 전에 명문화한다.
