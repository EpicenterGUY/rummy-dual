# 상태 3.0 구현 계약

이 문서는 승인된 18종의 **설계 계약**이다. 실제 구현은 `OFFICIAL_STATUS`에 등록된 15종이며, 잔향·불안정·반향 3종은 구현 대기다. 균열과 조합 표식은 [3차 구현](EFFECT_SYSTEM_3_WAVE3.md)을 따른다. 표식의 카드 범위는 아직 지원하지 않는다. 설명만 있는 상태를 라이브 카드에 넣지 않는다. 기존 상태 11종은 EFFECT_SYSTEM_3.md를 따른다.

## 공통 처리

- 상태값은 유한한 음수 아닌 정수다. 횟수형은 명시된 상한을 적용하고 기간형은 중첩하지 않고 더 늦은 만료까지만 갱신한다.
- 조합의 제어자는 보드 슬롯 소유자, 카드 제어자는 `owner`, 원주인은 `originOwner`다. 한 효과에서 이를 혼용하지 않는다.
- 상대의 카드/조합에 거는 불리한 상태는 적대 간섭 관문을 통과한다. 합법 대상/비용 확인 → 보호/대상 교대 → 상태 확정 순서다. 방어로 막힌 상태는 부여/소비 이벤트를 만들지 않는다.
- 행동마다 완료 식별자를 갖는다. 실패, 선택 취소, 미완료 선택창에는 이벤트를 발행하지 않는다. 한 카드의 동일 반응은 카드 UID와 효과 ID 및 턴 토큰으로 제한한다.
- 순환/재배치/교환/분할/합병 자체는 새 조합 허용 횟수, 스위치 반환, 버스트·체인 위력을 생성하지 않는다. 카드에 적힌 후속 위력만 별도 적용한다.
- 조합의 원래 유효성을 원자적으로 검증한다. 도중 임시 상태를 다른 효과가 관측하지 않도록 한다.

## 확장 7종의 계약 — 균열·침묵·가변·조합 표식 구현, 나머지 대기

|---|---|---|---|

| silence / 침묵 | 카드 | 지속 능력과 공개/손패 반응을 정지. 진입 시 1회 사용 효과와 카드의 원래 숫자·무늬는 유지 | 부여 당시 카드 제어자의 다음 턴 종료까지. 만료 주체는 소유권 변경에도 고정. 봉인 횟수는 소비하지 않음 |

| echo / 잔향 | 카드 | 다음 실제 네임드 효과의 복제 가능한 수치 행동 하나를 절반으로 재적용 | 비중첩 1. 첫 합법 수치 행동 해결 뒤 제거하고 내림한 복제 1회. 봉인·무효·대상 없음에서는 보존 |
| unstable / 불안정 X | 카드 | 부여 시 기록한 제어자의 턴 종료에 X가 1 감소하고 0이면 해당 카드를 소모 | 비중첩, 재부여 시 더 작은 남은 X. 자기 턴에 얻은 1은 당턴 종료, 상대 턴에 얻으면 다음 자기 턴 종료. 영역 이동으로 타이머 초기화 불가 |
| mark / 표식 | 조합 구현, 카드 대기 | 부여자를 기록하는 공용 조건. 자체 피해/보너스는 없음 | 각 부여자별 비중첩 1. 소비 카드가 명시할 때 그 부여자의 표식만 소비. 카드가 덱/버림패/소모패로 가거나 조합 정리 시 제거 |

### 침묵의 구현 게이트 — 6차 완료

특정 카드의 `tag` 검사만 끄면 다른 테마가 우회한다. 모든 공개·손패 패시브 조회와 이벤트 구독이 `canTrigger(card, timing)`을 통과하도록 바꾼 후에만 침묵을 등록한다. 이미 등록되어 기다리는 예약은 발동 시점에 원본 카드가 없어도 살아 있는 독립 효과이므로 침묵이 소급 취소하지 않는다.

[6차 구현](EFFECT_SYSTEM_3_WAVE6.md)에서 순수 조회인 `canTrigger()`와 `cardHasAbility()`를 공용·테마 구독, 손패/공개/버림패/소모패 반응 및 구조 보조 판정에 적용했다. `use` 시점은 침묵을 통과하고 기존 봉인 처리를 따른다. 기간은 기록한 제어자의 턴 종료 처리 마지막에 만료하며, 양쪽 모든 카드 영역을 검사한다. 재부여는 더 늦은 만료만 갱신한다. 카드에는 침묵 표시, 상세에는 만료 주체·시점이 나온다.

이미 공개된 숫자·무늬 대역은 구체적인 사용값으로 고정해 유지한다. 샛길은 기존 빈 숫자 한 칸, 밀수업자는 기존 허용 카드 UID만 유지하므로 침묵 중 다른 빈칸/카드로 허용을 옮기지 못한다. 손패의 새 능력 사용에는 이 예외가 없으며 공개 영역을 떠나면 고정 역할을 해제한다. 인쇄 숫자·무늬와 조커의 원래 와일드 성질은 바꾸지 않는다. 침묵 해제 후에는 원래 지속 능력이 재개된다.

손패 보유 기간과 행동 이력은 계속 기록한다. 이미 발급한 앙코르 반환 허가·퀵 리로드·돌입대장 준비와 계약의 후속 처리는 등록된 효과로 유지한다. 관측 일지는 진행 중인 관측 기록을 보존하되 침묵 중 새 관측을 시작하거나 보상을 지급하지 않는다. 해제 시 현재 공개 표적의 관측을 갱신한다.

### 가변의 구현 게이트 — 7차 완료

[7차 구현](EFFECT_SYSTEM_3_WAVE7.md)은 인쇄 숫자·무늬를 보존하고 선택값을 별도 공개 역할로 확정한다. 원래 값 유지도 허용하되 성공한 다음 배치에서 1회를 소비한다. 한 번에 숫자와 무늬를 함께 바꿀 수 없다. 위/아래 인쇄값이 다르면 먼저 인쇄 방향을 고르고 그 값에 가변을 적용한다. A 아래·K 위로 넘어갈 수 없고 K→A 순환은 없다. 조커는 가변을 받을 수 있지만 고유 와일드 성질을 유지하는 선택만 가능하다.

실제 손패 참조·소유권·중복 카드·최종 조합·슬롯/생성/반환/회수 제한을 먼저 검사하고, 선택값 확정과 소비 뒤 바로 공개한다. 미리보기·취소·불법/오래된 선택은 가변을 쓰지 않는다. 사용값 선택은 배치를 취소할 수 있으며, 진입이 이미 끝난 뒤의 가변 부여 대상 선택은 필수다. 후보가 많으면 카드별로 좁혀 고르고 모든 합법 후보를 보존한다. 무늬·숫자·인쇄 방향·소비 여부를 포함한 선택값을 확정 직전에 재검증한다.

공개 중 새로 받은 가변은 현재 사용값을 바꾸지 않으며 다음 손패 복귀 뒤에만 쓴다. 공개→공개 재배치/분할/합병은 현재 역할과 다음 가변을 유지한다. 회수·정리·개별 소모 등 공개 영역을 나가면 역할을 해제하며, 아직 쓰지 않은 가변은 남는다. 회수 후 붙이기 후보와 AI 평가는 손패로 돌아온 값을 기준으로 계산한다.

침묵은 이미 부여된 가변과 확정된 역할을 끄지 않는다. 가변 뒤에 위조범·도플갱어 같은 활성 고유 판정이 적용되며 도플갱어의 숫자 복사는 확정된 무늬를 바꾸지 않는다. 대역 배우의 귀환 조건은 인쇄 ♥와 실제 런 무늬를 비교한다. 하트 축제·치유 대상·샛길 보충·세트 추적·전장 안내는 확정된 재료 값을 읽는다. 인쇄 슬롯·덱 구성·해금 ID는 원래 값으로 유지한다.

### 잔향/재귀 함수

허용 primitive는 실제 해결한 회복, 보호막, 독립 위력 추가뿐이다. 드로우, 상태 부여, 비용, 자해, 회수/이동, 직접 스위치 반환, 또 다른 복제는 제외한다. 숫자는 UI HP 단위로 기록하고 내부 회복 단위 4배를 두 번 적용하지 않는다. 복제 기록에는 `copied:true`를 붙이고 복제본이 다시 복제 원본이 되지 않는다. 재귀 함수는 같은 행동에서 자신보다 먼저 실제 해결한 다른 네임드 기록 중 1개를 선택한다. 선택창 재개로 원효과/복제가 중복 실행되지 않아야 한다.

### 불안정으로 남은 조합이 깨지는 경우

0이 된 카드가 손패면 소모, 공개 카드면 그 카드를 제외한 결과를 검사한다. 3장 이상 원래 SET/RUN이 유지되면 해당 카드만 소모하고 RUN 체인 1 감소. 결과가 불법이면 해당 조합 전체를 한 번 정리한다. 해당 카드의 불안정을 먼저 제거하므로 정리 중 귀환해도 타이머가 재발화하지 않는다. 다른 카드의 귀환/명시적 보존은 정상 적용한다. 이미 덱·버림패·소모패에 있는 카드는 카운트다운을 제거하며 재소모하지 않는다. 이 규칙은 정리의 대상 범위를 명확히 하며, 불법 조합을 보드에 남기지 않는다.

### 표식과 표적/접전/우편

표적은 한 플레이어가 가리키는 조합 1개, 표식은 여러 대상에 남길 수 있는 공용 상태다. 표적 이동이 이전 표식을 자동 삭제하지 않는다. 소비 조건은 `내 표식`으로 명시한다. 접전·우편·부품은 공간/정체성 메타데이터이므로 이름이 비슷하다는 이유만으로 표식으로 치환하지 않는다.

## 공용 동사 계약

| 동사 | 이동/처리 | 비용·예외 |
|---|---|---|
| 순환 N | 선택한 손패 최대 N장을 덱 아래로 보낸 뒤 실제 보낸 수만큼 획득 | 후보 확정 후 이동. 빈 손패에서는 드로우 없음. 기본 정비 횟수와 별개 |
| 보존 | 조합 정리의 소모 대신 현재 제어자 손패 | 그 턴 조합 사용·효과 재발동 금지. 귀환(원주인)과 목적지 구분 |
| 회수 | 공개→손패 | 원래 조합 유지, 회수권/고정/당턴 반환 제한 공통 적용 |
| 재배치 | 공개→다른 공개 조합 | 기존 이동의 한국어 명칭. 양쪽 유효, 고정·보호·소유권 검사. 손패 및 회수 보상 없음 |
| 대체 | 손패 카드와 공개 카드의 원자적 교체 | 결과 합법, 고정/보호 검사. 빠진 카드에는 당턴 반환 재사용 금지 |
| 교환 | 서로 다른 공개 조합의 카드 1장씩 원자적 교체 | 양쪽 결과 합법. 카드 소유권 불변. 두 이동을 하나의 행동으로 기록 |
| 분할 | 6장 이상 내 RUN→각각 3장 이상 두 RUN | 빈 슬롯 필요, 두 결과에 기존 체인 유지, 새 조합 생성/반환 보상 없음 |
| 합병 | 내 두 RUN→유효한 하나의 RUN | 결과 체인은 두 원본의 최솟값. 상태는 상태별 합산/기간 규칙으로 통합, 유예 없음 |
| 예약 | 미래 완료 이벤트에 효과 1회 | 해결 전에 예약 제거. 원본 카드가 영역을 떠나도 유지. 전투 종료에 제거 |

분할 시 조합 상태는 원본 첫 번째 카드가 들어간 결과에 한 번만 이전한다. 합병 시 봉인·보호는 합산, 균열은 최대 1, 표식은 부여자별 최대 1이다. 고정된 조합 또는 고정 카드가 있는 런은 변형 불가. 모든 카드의 소유권·개별 상태는 그대로다. 결과 조합은 이번 턴 붙이기 불가이며 이전 표적·접전은 해제한다.

분할/합병은 카드에 의해 발생하는 예외이며 기본 새 조합 생성 제한의 환불 수단이 아니다. 대상 한정 예약은 조합 ID를 따라가고, 분할/합병으로 ID가 사라지면 취소한다. 위치 변경 시 임의 복제하지 않는다.

## 현재 구현한 예약 범위

[5차 구현](EFFECT_SYSTEM_3_WAVE5.md)부터 `reserveEffect()`는 아래의 완료 조건을 지원한다.

| 조건 | 보상 | 처리 시점 |
|---|---|---|
| 다음 내 회수 / 재배치 | 플레이어 장전·불굴 / 해당 내 카드 귀환 | 실제 이동 완료 뒤 |
| 지정한 런에 내 카드 붙이기 | 플레이어 장전·불굴 | 해당 붙이기의 반환과 네임드 해결이 끝난 뒤 |
| 다음 내 카드 공개 | 같은 카드에 귀환 / 보호 | 새 조합·붙이기 완료 시 그 조합에 남아 있는 사용 카드 중 내 카드 첫 장. 다중 사용의 선택 순서를 따름 |
| 다음 내 실제 반환 | 플레이어 장전 | 반환 가능 여부·횟수 검사를 통과한 뒤, 위력 상태 소비 전 |

발동자, 출처 UID·이름, 조건, 범위·상태·양, 대상 조합 참조, 만료를 저장한다. 같은 출처·조건·상태의 미해결 예약은 중첩하거나 만료를 갱신하지 않는다. 일치하는 예약을 큐에서 모두 먼저 제거한 뒤 해결하므로 재진입해도 두 번 발동하지 않는다. 독립 출처의 예약은 함께 해결된다.

기본 만료는 다음 자기 턴 종료이며, 역바이럴의 다음 반환 예약은 카드 문구에 턴 만료가 없으므로 실제 반환 또는 전투 종료까지 유지한다. 무가산 반환도 실제 반환이므로 이 예약은 장전을 부여하고 해결되지만, 장전 자체는 위력을 더하는 다음 반환까지 남는다. 반환 실패와 같은 런 연속 연장은 예약을 소비하지 않는다.

조합 한정 예약은 해당 조합의 정리·분할·합병·전체 재순환 때 취소한다. 원본 카드만 회수/소모되어도 대상 조합이 남아 있으면 예약은 유지한다. 공개 예약은 공개 조합 사이 이동·회수·보존·귀환으로 발동하지 않는다. 승리·패배·교착 무승부에서 예약을 모두 제거하고, 전투 종료 뒤 예약을 새로 만들지 않는다.

숫자 복제 예약과 이 범위를 넘는 선택 후속은 아직 구현하지 않았다. 그 기능을 요구하는 카드는 설계표에서 `planned`로 유지한다.
